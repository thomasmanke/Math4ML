1. Beyond Parameter Learning: The Motivating Hook

In our study of linear regression and logistic regression, machine learning followed a consistent parametric workflow:

\[ (X, y) \xrightarrow{\text{training}} \hat{\theta} \in \mathbb{R}^{p+1}, \qquad x_{\text{new}} \xrightarrow{\hat{\theta}} \hat{y} = \sigma\left(x_{\text{new}}^\top \hat{\theta}\right) \]

The entire training dataset is compressed into a fixed parameter vector \(\hat{\theta}\). Once \(\hat{\theta}\) is estimated, the original training data can be discarded.

NoteThe Core Question

Must machine learning always mean estimating a fixed vector of parameters?

k-Nearest Neighbors (kNN) provides an intuitive counterexample: it is an instance-based (or lazy) learning method. Instead of fitting a global equation, kNN stores the training observations and resolves queries by inspecting local neighborhoods.

Property Parameter-Based Models (Linear / Logistic) Instance-Based Models (kNN)
Model State Fixed parameter vector \(\hat{\theta}\) Retained training data \(\mathcal{D} = \{(x_i, y_i)\}\)
Training Cost Iterative optimization (e.g., gradient descent) Minimal (\(\mathcal{O}(1)\) storage)
Prediction Cost Quick inner product: \(\mathcal{O}(p)\) Distance search across dataset: \(\mathcal{O}(n \cdot p)\)
Decision Surface Global hyperplane: \(x^\top \theta = c\) Flexible, piece-wise local boundaries

If a new patient \(x^*\) arrives at the clinic with glucose \(122.0\,\text{mg/dL}\) and BMI \(27.5\,\text{kg/m}^2\), how should we classify their diabetes status?

2. The kNN Prediction Rule

Rather than computing a global score \(x^{*\top}\theta\), kNN identifies the \(k\) training observations that lie closest to \(x^*\) according to a distance metric.

2.1 The Neighborhood Index Set

Let \(N_k(x)\) denote the set of indices corresponding to the \(k\) nearest training points to query point \(x\):

\[ N_k(x) = \left\{ i \in \{1, \dots, n\} : d(x, x_i) \le d_{(k)}(x) \right\} \]

where \(d_{(k)}(x)\) represents the \(k\)-th smallest distance from \(x\) to all training observations.

2.2 Classification: Majority Voting

For categorical target variables (\(y \in \{0, 1\}\)), the classification rule takes the statistical mode across neighboring labels:

\[ \hat{y}(x) = \operatorname{mode}\left\{ y_i : i \in N_k(x) \right\} \]

To minimize binary voting ties, practitioners typically choose an odd integer for \(k\) (e.g., \(k \in \{3, 5, 7\}\)).

2.3 Class Probabilities vs. Logistic Regression

The local empirical proportion provides an intuitive estimate of class probability:

\[ \widehat{P}(Y = 1 \mid x) = \frac{1}{k}\sum_{i \in N_k(x)} \mathbb{1}(y_i = 1) \]

Parametric Logistic Regression: \[ P(Y = 1 \mid x) = \frac{1}{1 + e^{-(\theta_0 + x_1\theta_1 + x_2\theta_2)}} \] Imposes a rigid global sigmoidal transition.

Non-Parametric kNN: \[ \widehat{P}(Y = 1 \mid x) = \frac{1}{k} \sum_{i \in N_k(x)} y_i \] Estimates local empirical frequency directly.

2.4 kNN Regression: Local Averaging

The identical neighborhood principle applies to continuous outcomes (such as predicting Glycated Hemoglobin \(\text{HbA}_{1c}\) in \(\%\)):

\[ \hat{f}(x) = \frac{1}{k} \sum_{i \in N_k(x)} y_i \]

2.5 Worked Clinical Example

Suppose our query patient \(x^* = (122\,\text{mg/dL}, 27.5\,\text{kg/m}^2)\) is evaluated against a mini-reference panel of 5 patients:

3. Distance Metrics and Feature Scaling

The core assumption of kNN is that geometrically close observations share similar outcomes. The definition of distance is therefore a primary modeling assumption.

3.1 Euclidean Metric

For feature vectors \(x_i, x_j \in \mathbb{R}^p\), the standard Euclidean (\(L_2\)) distance is:

\[ d(x_i, x_j) = \lVert x_i - x_j \rVert_2 = \sqrt{\sum_{m=1}^p (x_{im} - x_{jm})^2} \]

3.2 The Unit Distortion Dilemma

In clinical practice, features possess vastly different physical dimensions and measurement scales: - Fasting Glucose: values range from \(70\) to \(200\,\text{mg/dL}\) (\(\text{variance } \sigma^2 \approx 800\)). - BMI: values range from \(18\) to \(40\,\text{kg/m}^2\) (\(\text{variance } \sigma^2 \approx 16\)).

When computing squared Euclidean differences:

\[ d^2(x_i, x_j) = \underbrace{(x_{i,\text{glucose}} - x_{j,\text{glucose}})^2}_{\approx 100 - 2500\,[\text{mg/dL}]^2} + \underbrace{(x_{i,\text{BMI}} - x_{j,\text{BMI}})^2}_{\approx 1 - 25\,[\text{kg/m}^2]^2} \]

The glucose coordinate completely dominates the sum! Without standardization, nearest neighbors are selected almost exclusively along the glucose axis, effectively discarding the clinical information contained in BMI.

3.3 Standardization (\(Z\)-Scores)

To give each feature equal geometric weighting, we standardize each coordinate using its sample mean \(\mu_j\) and sample standard deviation \(s_j\):

\[ z_{ij} = \frac{x_{ij} - \mu_j}{s_j} \]

ImportantData Leakage Prevention via Scikit-Learn Pipelines

Scaling statistics (\(\mu_j, s_j\)) must be computed strictly on the training set and then applied unchanged to validation or test queries.

In scikit-learn, always encapsulate preprocessing and modeling inside a Pipeline:

pipeline = Pipeline([
    ("scaler", StandardScaler()),
    ("knn", KNeighborsClassifier(n_neighbors=5))
])

4. Model Complexity: Bias, Variance, and Choosing \(k\)

In parametric regression, we control complexity via regularization penalties (\(\lambda\)). In kNN, the neighborhood size \(k\) is the primary complexity lever.

4.1 The Overfitting Paradox

How can a model that merely stores training data overfit?

  • Extreme Flexibility (\(k = 1\)): Each training point is its own nearest neighbor. The training error is zero (\(0\%\)). However, the decision boundary contorts around isolated outliers and noisy observations, yielding high variance and low bias.

  • Extreme Rigidity (\(k = n\)): The neighborhood includes all \(n\) training observations. The prediction collapses to the global sample majority class everywhere, yielding high bias and zero variance.

Neighborhood Size Flexibility Effective Degrees of Freedom (\(\mathrm{df} \approx n/k\)) Bias Variance Clinical Risk
Small (\(k = 1\)) High High (\(\approx n\)) Low High Overfitting to measurement noise
Intermediate (\(k \approx \sqrt{n}\)) Balanced Moderate Moderate Moderate Optimal generalization
Large (\(k \to n\)) Low Low (\(\to 1\)) High Low Underfitting (misses local risk clusters)

4.2 Tuning \(k\) via Cross-Validation

The hyperparameter \(k\) cannot be chosen by minimizing training error (which trivially selects \(k = 1\)). Instead, \(k\) must be evaluated using \(K\)-fold cross-validation on unseen validation folds.

5.3 Bias-Variance Validation Curve

Plot Training vs. Cross-Validation Accuracy Curve 
k_values = np.arange(1, 41, 2)
train_scores = []
cv_scores = []

for k in k_values:
    pipe = Pipeline([
        ("scaler", StandardScaler()),
        ("knn", KNeighborsClassifier(n_neighbors=k))
    ])
    pipe.fit(X_clinical, y)
    train_scores.append(pipe.score(X_clinical, y))
    cv_scores.append(np.mean(cross_val_score(pipe, X_clinical, y, cv=5)))

best_k = k_values[np.argmax(cv_scores)]

fig, ax = plt.subplots(figsize=(10, 4.2))
ax.plot(k_values, train_scores, 'o--', color='#2b5c8f', lw=2, label='Training Accuracy')
ax.plot(k_values, cv_scores, 's-', color='#d95f02', lw=2.5, label='5-Fold Cross-Validation Accuracy')

ax.axvline(best_k, color='gray', linestyle=':', lw=1.5, label=f'Optimal $k^* = {best_k}$')
ax.set_title("Bias-Variance Trade-off: Accuracy vs. Neighborhood Size $k$", fontsize=12, pad=10)
ax.set_xlabel("Neighborhood Size $k$", fontsize=11)
ax.set_ylabel("Classification Accuracy", fontsize=11)
ax.set_xticks(k_values[::2])
ax.legend(loc='lower left', frameon=True)
ax.grid(True, linestyle=':', alpha=0.5)

plt.tight_layout()
plt.show()

6. High Dimensions and Bridge to PCA

While kNN is conceptually clean and highly flexible in low dimensions (\(p = 2\) or \(3\)), its local assumption deteriorates rapidly as dimensionality grows—a phenomenon known as the Curse of Dimensionality.

6.1 The Volume Dilemma

Consider a unit hypercube in \(p\) dimensions: \([0, 1]^p\), with total volume \(V = 1\). Suppose we wish to capture a target fraction \(q \in (0, 1)\) of the data points using a sub-cube of side length \(r\):

\[ V_p(r) = r^p = q \implies r = q^{1/p} \]

Let us calculate the side length \(r\) required to capture just \(10\%\) of observations (\(q = 0.10\)):

Dimension \(p\) Formula \(r = 0.10^{1/p}\) Edge Length \(r\) Required Geometric Interpretation
\(p = 1\) \(0.10^1\) \(0.10\) Truly local segment (\(10\%\) of range)
\(p = 2\) \(0.10^{1/2}\) \(\approx 0.32\) Local box spanning \(32\%\) of coordinate range
\(p = 10\) \(0.10^{1/10}\) \(\approx 0.79\) Box spans \(79\%\) of each coordinate!
\(p = 20\) \(0.10^{1/20}\) \(\approx 0.89\) Spans nearly the entire feature domain (\(89\%\))

In 20 dimensions, to capture even \(10\%\) of neighboring points, our “neighborhood” must span almost the entirety of each coordinate axis! The neighborhood is no longer local.

6.2 The Bridge to Principal Component Analysis (PCA)

If high-dimensional space creates extreme data sparsity, can we extract a lower-dimensional representation that retains the primary variance before predicting?

\[ X \in \mathbb{R}^{n \times p} \xrightarrow{\text{Standardize}} Z \xrightarrow{\text{PCA}} Z_{1:r} \in \mathbb{R}^{n \times r} \xrightarrow{\text{kNN}} \hat{y} \]

This previews the fundamental motivation for Unsupervised Representation Learning: - PCA finds orthogonal axes of maximum variance without utilizing target labels \(y\). - Executing kNN in the reduced principal component space restores geometric density. - Caveat: Because PCA is unsupervised, directions of high variance do not necessarily guarantee optimal class separation.

7. Review & Grand Comparison

Dimension Linear / Logistic Regression k-Nearest Neighbors (kNN)
Model State Fixed parameter vector \(\hat{\theta} \in \mathbb{R}^{p+1}\) Retained training dataset \(\mathcal{D} = \{(x_i, y_i)\}\)
Prediction Function Global formula: \(\hat{y} = \sigma(x^\top \theta)\) Local search: \(\hat{y} = \operatorname{mode}\{y_i : i \in N_k(x)\}\)
Non-Linearity Requires manual basis expansions (\(x^2, x_1 x_2\)) Inherently non-linear and adaptive
Complexity Control Regularization penalties (\(\lambda_{\text{Ridge}}, \lambda_{\text{Lasso}}\)) Neighborhood size \(k\)
Feature Scaling Affects regularization penalties Critical: Directly distorts nearest neighbors
High Dimensions (\(p \gg 1\)) Controlled via \(L_1 / L_2\) penalties Severe breakdown (Curse of Dimensionality)
Local Interpretability Global weights \(\theta_j\) (Odds Ratios \(e^{\theta_j}\)) Direct inspection of neighboring patients

Concluding Synthesis

  1. Learning without Parameters: Machine learning does not require compressing data into a parameter vector. Instance-based models predict directly from local empirical evidence.
  2. The Metric is the Model: In kNN, assumptions are encoded in the distance metric and feature scaling, rather than in an explicit loss equation.
  3. Generalization over Memorization: Although kNN stores all data, tuning \(k\) via cross-validation prevents memorization and controls the bias-variance trade-off.

## 2. The kNN Prediction Rule

Rather than computing a global score $x^{*\top}\theta$, kNN identifies the $k$ training observations that lie closest to $x^*$ according to a distance metric.

### 2.1 The Neighborhood Index Set

Let $N_k(x)$ denote the set of indices corresponding to the $k$ nearest training points to query point $x$:

$$
N_k(x) = \left\{ i \in \{1, \dots, n\} : d(x, x_i) \le d_{(k)}(x) \right\}
$$

where $d_{(k)}(x)$ represents the $k$-th smallest distance from $x$ to all training observations.

### 2.2 Classification: Majority Voting

For categorical target variables ($y \in \{0, 1\}$), the classification rule takes the statistical **mode** across neighboring labels:

$$
\hat{y}(x) = \operatorname{mode}\left\{ y_i : i \in N_k(x) \right\}
$$

To minimize binary voting ties, practitioners typically choose an **odd** integer for $k$ (e.g., $k \in \{3, 5, 7\}$).

### 2.3 Class Probabilities vs. Logistic Regression

The local empirical proportion provides an intuitive estimate of class probability:

$$
\widehat{P}(Y = 1 \mid x) = \frac{1}{k}\sum_{i \in N_k(x)} \mathbb{1}(y_i = 1)
$$

::: {.columns}
::: {.column width="50%"}
**Parametric Logistic Regression:**
$$
P(Y = 1 \mid x) = \frac{1}{1 + e^{-(\theta_0 + x_1\theta_1 + x_2\theta_2)}}
$$
Imposes a rigid global sigmoidal transition.
:::

::: {.column width="50%"}
**Non-Parametric kNN:**
$$
\widehat{P}(Y = 1 \mid x) = \frac{1}{k} \sum_{i \in N_k(x)} y_i
$$
Estimates local empirical frequency directly.
:::
:::

### 2.4 kNN Regression: Local Averaging

The identical neighborhood principle applies to continuous outcomes (such as predicting Glycated Hemoglobin $\text{HbA}_{1c}$ in $\%$):

$$
\hat{f}(x) = \frac{1}{k} \sum_{i \in N_k(x)} y_i
$$

### 2.5 Worked Clinical Example

Suppose our query patient $x^* = (122\,\text{mg/dL}, 27.5\,\text{kg/m}^2)$ is evaluated against a mini-reference panel of 5 patients:

| Patient $i$ | Glucose ($x_{i1}$ [$\text{mg/dL}$]) | BMI ($x_{i2}$ [$\text{kg/m}^2$]) | Euclidean Distance $d(x^*, x_i)$ | Label $y_i$ | Rank |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | 120.0 | 28.0 | $\sqrt{(2.0)^2 + (-0.5)^2} \approx 2.06$ | Diabetic ($1$) | **1** |
| 2 | 124.0 | 26.5 | $\sqrt{(-2.0)^2 + (1.0)^2} \approx 2.24$ | Diabetic ($1$) | **2** |
| 3 | 119.0 | 29.0 | $\sqrt{(3.0)^2 + (-1.5)^2} \approx 3.35$ | Healthy ($0$) | **3** |
| 4 | 115.0 | 25.0 | $\sqrt{(7.0)^2 + (2.5)^2} \approx 7.43$ | Healthy ($0$) | 4 |
| 5 | 135.0 | 31.0 | $\sqrt{(-13.0)^2 + (-3.5)^2} \approx 13.46$ | Diabetic ($1$) | 5 |

For $k = 3$, the nearest neighbors are patients $\{1, 2, 3\}$:
- Label votes: $\{1, 1, 0\}$
- Majority prediction: $\hat{y}(x^*) = 1$ (Diabetic)
- Estimated probability: $\widehat{P}(Y = 1 \mid x^*) = \frac{2}{3} \approx 66.7\%$

## 3. Distance Metrics and Feature Scaling

The core assumption of kNN is that geometrically close observations share similar outcomes. The definition of distance is therefore a primary modeling assumption.

### 3.1 Euclidean Metric

For feature vectors $x_i, x_j \in \mathbb{R}^p$, the standard Euclidean ($L_2$) distance is:

$$
d(x_i, x_j) = \lVert x_i - x_j \rVert_2 = \sqrt{\sum_{m=1}^p (x_{im} - x_{jm})^2}
$$

### 3.2 The Unit Distortion Dilemma

In clinical practice, features possess vastly different physical dimensions and measurement scales:
- **Fasting Glucose:** values range from $70$ to $200\,\text{mg/dL}$ ($\text{variance } \sigma^2 \approx 800$).
- **BMI:** values range from $18$ to $40\,\text{kg/m}^2$ ($\text{variance } \sigma^2 \approx 16$).

When computing squared Euclidean differences:

$$
d^2(x_i, x_j) = \underbrace{(x_{i,\text{glucose}} - x_{j,\text{glucose}})^2}_{\approx 100 - 2500\,[\text{mg/dL}]^2} + \underbrace{(x_{i,\text{BMI}} - x_{j,\text{BMI}})^2}_{\approx 1 - 25\,[\text{kg/m}^2]^2}
$$

The glucose coordinate completely dominates the sum! Without standardization, nearest neighbors are selected almost exclusively along the glucose axis, effectively discarding the clinical information contained in BMI.

### 3.3 Standardization ($Z$-Scores)

To give each feature equal geometric weighting, we standardize each coordinate using its sample mean $\mu_j$ and sample standard deviation $s_j$:

$$
z_{ij} = \frac{x_{ij} - \mu_j}{s_j}
$$

::: {.callout-important}
### Data Leakage Prevention via Scikit-Learn Pipelines
Scaling statistics ($\mu_j, s_j$) must be computed strictly on the **training set** and then applied unchanged to validation or test queries. 

In `scikit-learn`, always encapsulate preprocessing and modeling inside a `Pipeline`:

```python
pipeline = Pipeline([
    ("scaler", StandardScaler()),
    ("knn", KNeighborsClassifier(n_neighbors=5))
])
```
:::

## 4. Model Complexity: Bias, Variance, and Choosing $k$

In parametric regression, we control complexity via regularization penalties ($\lambda$). In kNN, **the neighborhood size $k$ is the primary complexity lever**.

### 4.1 The Overfitting Paradox

How can a model that merely stores training data overfit?

- **Extreme Flexibility ($k = 1$):**
  Each training point is its own nearest neighbor. The training error is zero ($0\%$). However, the decision boundary contorts around isolated outliers and noisy observations, yielding **high variance and low bias**.

- **Extreme Rigidity ($k = n$):**
  The neighborhood includes all $n$ training observations. The prediction collapses to the global sample majority class everywhere, yielding **high bias and zero variance**.

| Neighborhood Size | Flexibility | Effective Degrees of Freedom ($\mathrm{df} \approx n/k$) | Bias | Variance | Clinical Risk |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **Small ($k = 1$)** | High | High ($\approx n$) | Low | High | Overfitting to measurement noise |
| **Intermediate ($k \approx \sqrt{n}$)** | Balanced | Moderate | Moderate | Moderate | Optimal generalization |
| **Large ($k \to n$)** | Low | Low ($\to 1$) | High | Low | Underfitting (misses local risk clusters) |

### 4.2 Tuning $k$ via Cross-Validation

The hyperparameter $k$ cannot be chosen by minimizing training error (which trivially selects $k = 1$). Instead, $k$ must be evaluated using $K$-fold cross-validation on unseen validation folds.

## 6. High Dimensions and Bridge to PCA

While kNN is conceptually clean and highly flexible in low dimensions ($p = 2$ or $3$), its local assumption deteriorates rapidly as dimensionality grows—a phenomenon known as the **Curse of Dimensionality**.

### 6.1 The Volume Dilemma

Consider a unit hypercube in $p$ dimensions: $[0, 1]^p$, with total volume $V = 1$. Suppose we wish to capture a target fraction $q \in (0, 1)$ of the data points using a sub-cube of side length $r$:

$$
V_p(r) = r^p = q \implies r = q^{1/p}
$$

Let us calculate the side length $r$ required to capture just **$10\%$ of observations** ($q = 0.10$):

| Dimension $p$ | Formula $r = 0.10^{1/p}$ | Edge Length $r$ Required | Geometric Interpretation |
| :---: | :---: | :---: | :--- |
| **$p = 1$** | $0.10^1$ | $0.10$ | Truly local segment ($10\%$ of range) |
| **$p = 2$** | $0.10^{1/2}$ | $\approx 0.32$ | Local box spanning $32\%$ of coordinate range |
| **$p = 10$** | $0.10^{1/10}$ | $\approx 0.79$ | Box spans $79\%$ of each coordinate! |
| **$p = 20$** | $0.10^{1/20}$ | $\approx 0.89$ | Spans nearly the entire feature domain ($89\%$) |

In 20 dimensions, to capture even $10\%$ of neighboring points, our "neighborhood" must span almost the entirety of each coordinate axis! **The neighborhood is no longer local.**

### 6.2 The Bridge to Principal Component Analysis (PCA)

If high-dimensional space creates extreme data sparsity, can we extract a lower-dimensional representation that retains the primary variance before predicting?

$$
X \in \mathbb{R}^{n \times p} \xrightarrow{\text{Standardize}} Z \xrightarrow{\text{PCA}} Z_{1:r} \in \mathbb{R}^{n \times r} \xrightarrow{\text{kNN}} \hat{y}
$$

This previews the fundamental motivation for **Unsupervised Representation Learning**:
- PCA finds orthogonal axes of maximum variance without utilizing target labels $y$.
- Executing kNN in the reduced principal component space restores geometric density.
- *Caveat:* Because PCA is unsupervised, directions of high variance do not necessarily guarantee optimal class separation.

## 7. Review & Grand Comparison

| Dimension | Linear / Logistic Regression | k-Nearest Neighbors (kNN) |
| :--- | :--- | :--- |
| **Model State** | Fixed parameter vector $\hat{\theta} \in \mathbb{R}^{p+1}$ | Retained training dataset $\mathcal{D} = \{(x_i, y_i)\}$ |
| **Prediction Function** | Global formula: $\hat{y} = \sigma(x^\top \theta)$ | Local search: $\hat{y} = \operatorname{mode}\{y_i : i \in N_k(x)\}$ |
| **Non-Linearity** | Requires manual basis expansions ($x^2, x_1 x_2$) | Inherently non-linear and adaptive |
| **Complexity Control** | Regularization penalties ($\lambda_{\text{Ridge}}, \lambda_{\text{Lasso}}$) | Neighborhood size $k$ |
| **Feature Scaling** | Affects regularization penalties | **Critical**: Directly distorts nearest neighbors |
| **High Dimensions ($p \gg 1$)** | Controlled via $L_1 / L_2$ penalties | Severe breakdown (Curse of Dimensionality) |
| **Local Interpretability** | Global weights $\theta_j$ (Odds Ratios $e^{\theta_j}$) | Direct inspection of neighboring patients |

### Concluding Synthesis

1. **Learning without Parameters:** Machine learning does not require compressing data into a parameter vector. Instance-based models predict directly from local empirical evidence.
2. **The Metric is the Model:** In kNN, assumptions are encoded in the distance metric and feature scaling, rather than in an explicit loss equation.
3. **Generalization over Memorization:** Although kNN stores all data, tuning $k$ via cross-validation prevents memorization and controls the bias-variance trade-off.
