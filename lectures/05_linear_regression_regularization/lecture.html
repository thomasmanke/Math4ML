1. The Bias-Variance Tradeoff: Concept & Formal Decomposition

In Lecture 04, we witnessed the two opposing extremes of model flexibility:

  • Underfitting (High Bias): A rigid straight line (\(d = 1\)) fails to capture the underlying biological U-shaped curve, leaving non-random parabolic patterns in the residuals.
  • Overfitting (High Variance): A high-degree polynomial (\(d = 12\)) wiggles through every idiosyncrasy of the training data, exhibiting wild boundary oscillations, exploding parameter weights, and a near-singular Gram matrix.

How do we formalize this tradeoff mathematically?

1.1 The Visual Target: The Dartboard Analogy

To intuitively separate Bias from Variance, imagine firing arrows at a target bullseye. The center represents the true biological mechanism \(f(x)\), and each shot represents a model \(\hat{f}(x)\) trained on an independent random patient cohort \(\mathcal{D}_k\):

Generate 4-Panel Dartboard Target Plot 
fig, axes = plt.subplots(1, 4, figsize=(10, 3.5))

  • Bias: The distance between the average prediction \(\mathbb{E}[\hat{f}(x)]\) across cohorts and the true bullseye \(f(x)\).
  • Variance: How widely dispersed predictions \(\hat{f}(x)\) scatter around their own average.

1.2 Mathematical Derivation of the Bias-Variance Decomposition

Let us now derive why expected generalization error decomposes strictly into these two components plus irreducible noise.

Mathematical Setup:

  1. True biological data-generating process: \(y = f(x) + \varepsilon\).
  2. Measurement noise \(\varepsilon\) has mean \(\mathbb{E}[\varepsilon] = 0\) and constant variance \(\operatorname{Var}(\varepsilon) = \sigma^2\).
  3. Noise \(\varepsilon\) in a new test observation is independent of the model estimate \(\hat{f}(x)\) trained on historical data.

Let \(\hat{f}(x)\) be the model learned from a random training set \(\mathcal{D}\). Because \(\mathcal{D}\) is random, \(\hat{f}(x)\) is a random variable. Let \(\bar{f}(x) = \mathbb{E}[\hat{f}(x)]\) denote the expected model prediction averaged across all possible training cohorts.

Step 1: Expand the Expected Squared Prediction Error

\[\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \mathbb{E}\left[\left( (f(x) + \varepsilon) - \hat{f}(x) \right)^2\right]\]

Regroup into model error \((f(x) - \hat{f}(x))\) and noise \(\varepsilon\):

\[\begin{aligned} \mathbb{E}\left[(y - \hat{f}(x))^2\right] &= \mathbb{E}\left[\left( (f(x) - \hat{f}(x)) + \varepsilon \right)^2\right] \\ &= \mathbb{E}\left[(f(x) - \hat{f}(x))^2\right] + 2\mathbb{E}[(f(x) - \hat{f}(x))\varepsilon] + \mathbb{E}[\varepsilon^2] \end{aligned}\]

Because \(\varepsilon\) is independent of \(\hat{f}(x)\) and \(\mathbb{E}[\varepsilon] = 0\): \[\mathbb{E}[(f(x) - \hat{f}(x))\varepsilon] = \mathbb{E}[f(x) - \hat{f}(x)] \cdot \mathbb{E}[\varepsilon] = 0\] \[\mathbb{E}[\varepsilon^2] = \operatorname{Var}(\varepsilon) = \sigma^2\]

Thus, total error separates into model error plus noise: \[\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \mathbb{E}\left[(f(x) - \hat{f}(x))^2\right] + \sigma^2\]

Step 2: Decompose the Model Error

Add and subtract the expected prediction \(\bar{f}(x) = \mathbb{E}[\hat{f}(x)]\) inside the expectation:

\[\begin{aligned} \mathbb{E}\left[(f(x) - \hat{f}(x))^2\right] &= \mathbb{E}\left[\left( (f(x) - \bar{f}(x)) + (\bar{f}(x) - \hat{f}(x)) \right)^2\right] \\ &= \mathbb{E}\left[(f(x) - \bar{f}(x))^2\right] + 2\mathbb{E}\left[(f(x) - \bar{f}(x))(\bar{f}(x) - \hat{f}(x))\right] + \mathbb{E}\left[(\bar{f}(x) - \hat{f}(x))^2\right] \end{aligned}\]

Notice that \((f(x) - \bar{f}(x))\) is a deterministic constant (independent of the training sample \(\mathcal{D}\)). Therefore: \[\mathbb{E}\left[(f(x) - \bar{f}(x))(\bar{f}(x) - \hat{f}(x))\right] = (f(x) - \bar{f}(x)) \cdot \mathbb{E}[\bar{f}(x) - \hat{f}(x)]\]

By definition of expectation, \(\mathbb{E}[\bar{f}(x) - \hat{f}(x)] = \bar{f}(x) - \mathbb{E}[\hat{f}(x)] = 0\). The cross-term vanishes completely!

The Final Identity:

\[\boxed{\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \underbrace{(f(x) - \bar{f}(x))^2}_{\text{Bias}^2(\hat{f}(x))} + \underbrace{\mathbb{E}\left[(\hat{f}(x) - \bar{f}(x))^2\right]}_{\operatorname{Var}(\hat{f}(x))} + \underbrace{\sigma^2}_{\text{Irreducible Noise}}}\]

NoteThe Three Inescapable Error Components
  1. \(\text{Bias}^2(\hat{f}(x))\): Systematic error from oversimplified assumptions (e.g., forcing a straight line onto curved biology).
  2. \(\operatorname{Var}(\hat{f}(x))\): Model volatility across different patient cohorts (e.g., high-degree polynomials whose weights swing wildly).
  3. \(\sigma^2\): Irreducible noise inherent to the biological system. No algorithm can ever predict below \(\sigma^2\).

2. Detecting Overfitting Empirically: Validation Splits & The U-Curve

Because we never have access to the true data-generating function \(f(x)\) in practice, we cannot compute theoretical Bias or Variance directly. How do we detect whether our model is underfitting or overfitting?

2.1 The Golden Rule of Machine Learning

We split our available data into two independent sets: 1. Training Set (\(\mathcal{D}_{\text{train}}\)): Used exclusively to estimate the parameter vector \(\hat{\boldsymbol{\theta}}\). 2. Validation Set (\(\mathcal{D}_{\text{val}}\)): Held out during training and used exclusively to evaluate generalization performance.

Generate Empirical Validation U-Curve 
np.random.seed(42)
n_total = 200
x_all = np.random.uniform(16.0, 45.0, n_total)
y_all = 2.0 + 0.040 * (x_all - 22.5)**2 + np.random.normal(0, 1.2, n_total)
y_all = np.clip(y_all, 0.5, None)

x_tr, x_val, y_tr, y_val = train_test_split(x_all, y_all, test_size=0.30, random_state=42)

poly_range = list(range(1, 11))
train_losses = []
val_losses = []

for d in poly_range:
    model = make_pipeline(PolynomialFeatures(d), LinearRegression())
    model.fit(x_tr.reshape(-1, 1), y_tr)
    train_losses.append(np.mean((y_tr - model.predict(x_tr.reshape(-1, 1)))**2))
    val_losses.append(np.mean((y_val - model.predict(x_val.reshape(-1, 1)))**2))

fig, ax = plt.subplots(figsize=(8.5, 4.5))
ax.plot(poly_range, train_losses, 'o-', color='#1f77b4', lw=2, label='Training Loss (MSE)')
ax.plot(poly_range, val_losses, 's--', color='crimson', lw=2.2, label='Validation Loss (MSE)')
ax.set_title('Model Complexity: Training vs. Validation Loss (The U-Curve)')
ax.set_xlabel('Polynomial Degree $d$')
ax.set_ylabel('Mean Squared Error')
ax.set_xticks(poly_range)
ax.set_ylim(0, 5)
ax.axvline(2, color='darkgreen', linestyle=':', lw=2, label='Optimal Complexity ($d=2$)')
ax.legend(loc='upper right', fontsize=9)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

3. \(L_2\) Ridge Regularization: Analytical Shrinkage & Invertibility Rescue

In Lecture 04, we discovered that as polynomial degree increases, two severe breakdowns occur: 1. Parameter weights explode to massive opposing magnitudes (\(\pm 10^6\)). 2. The Gram matrix determinant \(\det(\mathbf{X}^T\mathbf{X}) \to 0\) collapses exponentially toward zero, making \(\mathbf{X}^T\mathbf{X}\) practically or strictly non-invertible.

Rather than manually pruning features, Ridge Regression (\(L_2\) Regularization) adds a penalty on the squared Euclidean norm of the parameter vector to the cost function:

\[J_{\text{Ridge}}(\boldsymbol{\theta}) = \|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|_2^2 + \lambda \|\boldsymbol{\theta}\|_2^2 = (\mathbf{y} - \mathbf{X}\boldsymbol{\theta})^T(\mathbf{y} - \mathbf{X}\boldsymbol{\theta}) + \lambda \boldsymbol{\theta}^T\boldsymbol{\theta}\]

where \(\lambda \ge 0\) is the regularization hyperparameter: * \(\lambda = 0\): Recovers standard Ordinary Least Squares. * \(\lambda \to \infty\): Drives all weights toward zero (\(\hat{\boldsymbol{\theta}} \to \mathbf{0}\)).

3.1 Analytical Derivation of the Ridge Normal Equations

Because the \(L_2\) penalty is quadratic and continuously differentiable everywhere, we can solve for \(\hat{\boldsymbol{\theta}}_{\text{Ridge}}\) in closed form:

  1. Expand the objective function: \[J(\boldsymbol{\theta}) = \mathbf{y}^T\mathbf{y} - 2\boldsymbol{\theta}^T\mathbf{X}^T\mathbf{y} + \boldsymbol{\theta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\theta} + \lambda \boldsymbol{\theta}^T\boldsymbol{\theta}\]

  2. Take the vector gradient with respect to \(\boldsymbol{\theta}\): \[\nabla_{\boldsymbol{\theta}} J = -2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\boldsymbol{\theta} + 2\lambda\boldsymbol{\theta}\]

  3. Set the gradient to zero for optimality: \[\mathbf{X}^T\mathbf{X}\hat{\boldsymbol{\theta}} + \lambda\hat{\boldsymbol{\theta}} = \mathbf{X}^T\mathbf{y} \implies (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})\hat{\boldsymbol{\theta}} = \mathbf{X}^T\mathbf{y}\]

  4. Closed-form analytical solution: \[\boxed{\hat{\boldsymbol{\theta}}_{\text{Ridge}} = (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}}\]

3.2 Rescuing the Collapsing Gram Matrix: The Eigenvalue Shift

Notice what adding \(\lambda\mathbf{I}\) accomplishes algebraically:

In Lecture 04, we saw that as columns of \(\mathbf{X}\) become collinear, the smallest eigenvalues of \(\mathbf{X}^T\mathbf{X}\) plunge toward zero: \(\lambda_{\min} \to 0\).

If \(\mathbf{X}^T\mathbf{X}\) has eigenvalues \(\lambda_i \ge 0\), then the regularized matrix \(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I}\) has eigenvalues: \[\tilde{\lambda}_i = \lambda_i + \lambda \ge \lambda > 0 \qquad \text{for all } i\]

Its determinant is strictly positive: \[\det(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I}) = \prod_{i=1}^p (\lambda_i + \lambda) \ge \lambda^p > 0\]

The Fundamental Mathematical Guarantee: For any \(\lambda > 0\), the regularized matrix \((\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})\) is guaranteed to be strictly positive-definite and non-singular, even when \(p > n\) or when features are perfectly collinear! Ridge regression completely eliminates the numerical instability observed in Lecture 04.

4. \(L_1\) Lasso Regularization: Geometric Sparsity

While Ridge shrinks coefficients continuously toward zero, it never sets any weight exactly to zero.

Lasso Regression (\(L_1\) Regularization) replaces the squared \(L_2\) penalty with the sum of absolute values:

\[J_{\text{Lasso}}(\boldsymbol{\theta}) = \|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|_2^2 + \lambda \|\boldsymbol{\theta}\|_1 = \sum_{i=1}^n (y_i - \mathbf{x}_i^T\boldsymbol{\theta})^2 + \lambda \sum_{j=1}^p |\theta_j|\]

Because the absolute value function \(|\theta_j|\) is non-differentiable at \(\theta_j = 0\), Lasso has no closed-form solution and is solved numerically via coordinate descent.

4.1 The Geometric Diamond Argument

To understand why Lasso produces exact zeros (sparsity), consider the equivalent constrained optimization formulations:

\[\min_{\boldsymbol{\theta}} \text{RSS}(\boldsymbol{\theta}) \quad \text{subject to} \quad \begin{cases} \|\boldsymbol{\theta}\|_2^2 \le C & \text{(Ridge)} \\ \|\boldsymbol{\theta}\|_1 \le C & \text{(Lasso)} \end{cases}\]

  • Ridge (\(L_2\) Ball): The constraint boundary is a smooth sphere/circle. The elliptical contours of the RSS objective contact the circle at arbitrary smooth points, where neither coordinate is zero.
  • Lasso (\(L_1\) Diamond): The constraint boundary has sharp corners located precisely on the coordinate axes (\(\theta_1 = 0\) or \(\theta_2 = 0\)). An expanding elliptical RSS contour contacts these sharp corners first with high probability.

Thus, Lasso performs automatic feature selection, driving irrelevant or redundant feature weights strictly to zero!

5. Regularization Weight Paths: Ridge vs. Lasso

Let us compare how the estimated polynomial coefficients behave as the regularization penalty \(\lambda\) increases:

Generate Ridge vs. Lasso Weight Paths 
from sklearn.preprocessing import StandardScaler

# Degree 6 polynomial features on normalized BMI
x_norm = (x_all - x_all.min()) / (x_all.max() - x_all.min())
y_data = y_all
deg_path = 6
X_poly_raw = np.column_stack([x_norm**k for k in range(1, deg_path + 1)])
scaler = StandardScaler()
X_poly_scaled = scaler.fit_transform(X_poly_raw)

alphas = np.logspace(-3, 2, 100)
ridge_coefs = []
lasso_coefs = []

for a in alphas:
    r = Ridge(alpha=a, fit_intercept=True).fit(X_poly_scaled, y_data)
    l = Lasso(alpha=a, max_iter=10000, fit_intercept=True).fit(X_poly_scaled, y_data)
    ridge_coefs.append(r.coef_)
    lasso_coefs.append(l.coef_)

fig, axes = plt.subplots(1, 2, figsize=(10, 4.5))

axes[0].plot(alphas, ridge_coefs, lw=1.8)
axes[0].set_xscale('log')
axes[0].set_title('Ridge ($L_2$): Asymptotic Shrinkage')
axes[0].set_xlabel(r'Regularization Strength $\lambda$')
axes[0].set_ylabel('Standardized Coefficients')
axes[0].grid(True, alpha=0.3)

axes[1].plot(alphas, lasso_coefs, lw=1.8)
axes[1].set_xscale('log')
axes[1].set_title('Lasso ($L_1$): Exact Threshold Sparsity')
axes[1].set_xlabel(r'Regularization Strength $\lambda$')
axes[1].set_ylabel('Standardized Coefficients')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

6. Andrew Ng’s Empirical Machine Learning Diagnostics

When an applied machine learning model performs poorly on unseen test patients, what concrete action should an engineer take?

In Stanford CS229, Andrew Ng formalized a rigorous diagnostic methodology based on Learning Curves (plotting training and validation error as a function of training sample size \(m\)).

Generate Andrew Ng Learning Curves 
m_sizes = np.linspace(20, 200, 10, dtype=int)
train_err_bias, val_err_bias = [], []
train_err_var, val_err_var = [], []

for m in m_sizes:
    x_sub = x_all[:m]
    y_sub = y_all[:m]
    
    # High Bias Model (Degree 1)
    m_bias = LinearRegression().fit(x_sub.reshape(-1, 1), y_sub)
    train_err_bias.append(np.mean((y_sub - m_bias.predict(x_sub.reshape(-1, 1)))**2))
    val_err_bias.append(np.mean((y_val - m_bias.predict(x_val.reshape(-1, 1)))**2))
    
    # High Variance Model (Degree 8, unregularized)
    m_var = make_pipeline(PolynomialFeatures(8), LinearRegression()).fit(x_sub.reshape(-1, 1), y_sub)
    train_err_var.append(np.mean((y_sub - m_var.predict(x_sub.reshape(-1, 1)))**2))
    val_err_var.append(np.mean((y_val - m_var.predict(x_val.reshape(-1, 1)))**2))

fig, axes = plt.subplots(1, 2, figsize=(10, 4.5))

axes[0].plot(m_sizes, train_err_bias, 'o-', color='#1f77b4', lw=2, label='Training Loss')
axes[0].plot(m_sizes, val_err_bias, 's--', color='crimson', lw=2, label='Validation Loss')
axes[0].axhline(2.8, color='black', linestyle=':', label='High Error Plateau')
axes[0].set_title('High Bias (Underfitting): More Data Will NOT Help')
axes[0].set_xlabel('Training Sample Size $m$')
axes[0].set_ylabel('Mean Squared Error')
axes[0].legend(fontsize=8, loc='center right')
axes[0].grid(True, alpha=0.3)

axes[1].plot(m_sizes, train_err_var, 'o-', color='#1f77b4', lw=2, label='Training Loss')
axes[1].plot(m_sizes, val_err_var, 's--', color='crimson', lw=2, label='Validation Loss')
axes[1].set_title('High Variance (Overfitting): More Data Helps')
axes[1].set_xlabel('Training Sample Size $m$')
axes[1].set_ylabel('Mean Squared Error')
axes[1].set_ylim(0, 10)
axes[1].legend(fontsize=8, loc='upper right')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

6.1 Andrew Ng’s 6 Diagnostic Actions

Diagnostic Finding Root Pathology Recommended Corrective Action Why it Works
Large Gap (\(J_{\text{val}} \gg J_{\text{train}}\)) High Variance Collect more training data (\(m \uparrow\)) Constrains high-degree flexibility
Large Gap (\(J_{\text{val}} \gg J_{\text{train}}\)) High Variance Reduce number of features (\(p \downarrow\)) Reduces model degrees of freedom
Large Gap (\(J_{\text{val}} \gg J_{\text{train}}\)) High Variance Increase regularization (\(\lambda \uparrow\)) Shrinks weights and conditions Gram matrix
High Plateau (\(J_{\text{train}} \approx J_{\text{val}}\) both high) High Bias Engineer polynomial / interaction features Enriches hypothesis space
High Plateau (\(J_{\text{train}} \approx J_{\text{val}}\) both high) High Bias Add new clinical predictors Provides unobserved physical signal
High Plateau (\(J_{\text{train}} \approx J_{\text{val}}\) both high) High Bias Decrease regularization (\(\lambda \downarrow\)) Relieves artificial constraints on weights

## 1. The Bias-Variance Tradeoff: Concept & Formal Decomposition

In Lecture 04, we witnessed the two opposing extremes of model flexibility:

* **Underfitting (High Bias):** A rigid straight line ($d = 1$) fails to capture the underlying biological U-shaped curve, leaving non-random parabolic patterns in the residuals.
* **Overfitting (High Variance):** A high-degree polynomial ($d = 12$) wiggles through every idiosyncrasy of the training data, exhibiting wild boundary oscillations, exploding parameter weights, and a near-singular Gram matrix.

How do we formalize this tradeoff mathematically?

To intuitively separate Bias from Variance, imagine firing arrows at a target bullseye. The center represents the true biological mechanism $f(x)$, and each shot represents a model $\hat{f}(x)$ trained on an independent random patient cohort $\mathcal{D}_k$:


* **Bias:** The distance between the average prediction $\mathbb{E}[\hat{f}(x)]$ across cohorts and the true bullseye $f(x)$.
* **Variance:** How widely dispersed predictions $\hat{f}(x)$ scatter around their own average.

### 1.2 Mathematical Derivation of the Bias-Variance Decomposition

Let us now derive why expected generalization error decomposes strictly into these two components plus irreducible noise.

#### Mathematical Setup:
1. True biological data-generating process: $y = f(x) + \varepsilon$.
2. Measurement noise $\varepsilon$ has mean $\mathbb{E}[\varepsilon] = 0$ and constant variance $\operatorname{Var}(\varepsilon) = \sigma^2$.
3. Noise $\varepsilon$ in a new test observation is independent of the model estimate $\hat{f}(x)$ trained on historical data.

Let $\hat{f}(x)$ be the model learned from a random training set $\mathcal{D}$. Because $\mathcal{D}$ is random, $\hat{f}(x)$ is a random variable.
Let $\bar{f}(x) = \mathbb{E}[\hat{f}(x)]$ denote the **expected model prediction** averaged across all possible training cohorts.

#### Step 1: Expand the Expected Squared Prediction Error

$$\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \mathbb{E}\left[\left( (f(x) + \varepsilon) - \hat{f}(x) \right)^2\right]$$

Regroup into model error $(f(x) - \hat{f}(x))$ and noise $\varepsilon$:

$$\begin{aligned}
\mathbb{E}\left[(y - \hat{f}(x))^2\right] &= \mathbb{E}\left[\left( (f(x) - \hat{f}(x)) + \varepsilon \right)^2\right] \\
&= \mathbb{E}\left[(f(x) - \hat{f}(x))^2\right] + 2\mathbb{E}[(f(x) - \hat{f}(x))\varepsilon] + \mathbb{E}[\varepsilon^2]
\end{aligned}$$

Because $\varepsilon$ is independent of $\hat{f}(x)$ and $\mathbb{E}[\varepsilon] = 0$:
$$\mathbb{E}[(f(x) - \hat{f}(x))\varepsilon] = \mathbb{E}[f(x) - \hat{f}(x)] \cdot \mathbb{E}[\varepsilon] = 0$$
$$\mathbb{E}[\varepsilon^2] = \operatorname{Var}(\varepsilon) = \sigma^2$$

Thus, total error separates into model error plus noise:
$$\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \mathbb{E}\left[(f(x) - \hat{f}(x))^2\right] + \sigma^2$$

#### Step 2: Decompose the Model Error

Add and subtract the expected prediction $\bar{f}(x) = \mathbb{E}[\hat{f}(x)]$ inside the expectation:

$$\begin{aligned}
\mathbb{E}\left[(f(x) - \hat{f}(x))^2\right] &= \mathbb{E}\left[\left( (f(x) - \bar{f}(x)) + (\bar{f}(x) - \hat{f}(x)) \right)^2\right] \\
&= \mathbb{E}\left[(f(x) - \bar{f}(x))^2\right] + 2\mathbb{E}\left[(f(x) - \bar{f}(x))(\bar{f}(x) - \hat{f}(x))\right] + \mathbb{E}\left[(\bar{f}(x) - \hat{f}(x))^2\right]
\end{aligned}$$

Notice that $(f(x) - \bar{f}(x))$ is a **deterministic constant** (independent of the training sample $\mathcal{D}$). Therefore:
$$\mathbb{E}\left[(f(x) - \bar{f}(x))(\bar{f}(x) - \hat{f}(x))\right] = (f(x) - \bar{f}(x)) \cdot \mathbb{E}[\bar{f}(x) - \hat{f}(x)]$$

By definition of expectation, $\mathbb{E}[\bar{f}(x) - \hat{f}(x)] = \bar{f}(x) - \mathbb{E}[\hat{f}(x)] = 0$. The cross-term vanishes completely!

#### The Final Identity:

$$\boxed{\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \underbrace{(f(x) - \bar{f}(x))^2}_{\text{Bias}^2(\hat{f}(x))} + \underbrace{\mathbb{E}\left[(\hat{f}(x) - \bar{f}(x))^2\right]}_{\operatorname{Var}(\hat{f}(x))} + \underbrace{\sigma^2}_{\text{Irreducible Noise}}}$$

::: {.callout-note}
### The Three Inescapable Error Components
1. **$\text{Bias}^2(\hat{f}(x))$**: Systematic error from oversimplified assumptions (e.g., forcing a straight line onto curved biology).
2. **$\operatorname{Var}(\hat{f}(x))$**: Model volatility across different patient cohorts (e.g., high-degree polynomials whose weights swing wildly).
3. **$\sigma^2$**: Irreducible noise inherent to the biological system. No algorithm can ever predict below $\sigma^2$.
:::

## 3. $L_2$ Ridge Regularization: Analytical Shrinkage & Invertibility Rescue

In Lecture 04, we discovered that as polynomial degree increases, two severe breakdowns occur:
1. Parameter weights explode to massive opposing magnitudes ($\pm 10^6$).
2. The Gram matrix determinant $\det(\mathbf{X}^T\mathbf{X}) \to 0$ collapses exponentially toward zero, making $\mathbf{X}^T\mathbf{X}$ practically or strictly non-invertible.

Rather than manually pruning features, **Ridge Regression ($L_2$ Regularization)** adds a penalty on the squared Euclidean norm of the parameter vector to the cost function:

$$J_{\text{Ridge}}(\boldsymbol{\theta}) = \|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|_2^2 + \lambda \|\boldsymbol{\theta}\|_2^2 = (\mathbf{y} - \mathbf{X}\boldsymbol{\theta})^T(\mathbf{y} - \mathbf{X}\boldsymbol{\theta}) + \lambda \boldsymbol{\theta}^T\boldsymbol{\theta}$$

where $\lambda \ge 0$ is the **regularization hyperparameter**:
* $\lambda = 0$: Recovers standard Ordinary Least Squares.
* $\lambda \to \infty$: Drives all weights toward zero ($\hat{\boldsymbol{\theta}} \to \mathbf{0}$).

### 3.1 Analytical Derivation of the Ridge Normal Equations

Because the $L_2$ penalty is quadratic and continuously differentiable everywhere, we can solve for $\hat{\boldsymbol{\theta}}_{\text{Ridge}}$ in closed form:

1. Expand the objective function:
   $$J(\boldsymbol{\theta}) = \mathbf{y}^T\mathbf{y} - 2\boldsymbol{\theta}^T\mathbf{X}^T\mathbf{y} + \boldsymbol{\theta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\theta} + \lambda \boldsymbol{\theta}^T\boldsymbol{\theta}$$

2. Take the vector gradient with respect to $\boldsymbol{\theta}$:
   $$\nabla_{\boldsymbol{\theta}} J = -2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\boldsymbol{\theta} + 2\lambda\boldsymbol{\theta}$$

3. Set the gradient to zero for optimality:
   $$\mathbf{X}^T\mathbf{X}\hat{\boldsymbol{\theta}} + \lambda\hat{\boldsymbol{\theta}} = \mathbf{X}^T\mathbf{y} \implies (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})\hat{\boldsymbol{\theta}} = \mathbf{X}^T\mathbf{y}$$

4. Closed-form analytical solution:
   $$\boxed{\hat{\boldsymbol{\theta}}_{\text{Ridge}} = (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}}$$

### 3.2 Rescuing the Collapsing Gram Matrix: The Eigenvalue Shift

Notice what adding $\lambda\mathbf{I}$ accomplishes algebraically:

In Lecture 04, we saw that as columns of $\mathbf{X}$ become collinear, the smallest eigenvalues of $\mathbf{X}^T\mathbf{X}$ plunge toward zero: $\lambda_{\min} \to 0$.

If $\mathbf{X}^T\mathbf{X}$ has eigenvalues $\lambda_i \ge 0$, then the regularized matrix $\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I}$ has eigenvalues:
$$\tilde{\lambda}_i = \lambda_i + \lambda \ge \lambda > 0 \qquad \text{for all } i$$

Its determinant is strictly positive:
$$\det(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I}) = \prod_{i=1}^p (\lambda_i + \lambda) \ge \lambda^p > 0$$

**The Fundamental Mathematical Guarantee:** For any $\lambda > 0$, the regularized matrix $(\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})$ is **guaranteed to be strictly positive-definite and non-singular**, even when $p > n$ or when features are perfectly collinear! Ridge regression completely eliminates the numerical instability observed in Lecture 04.

## 4. $L_1$ Lasso Regularization: Geometric Sparsity

While Ridge shrinks coefficients continuously toward zero, it never sets any weight *exactly* to zero.

**Lasso Regression ($L_1$ Regularization)** replaces the squared $L_2$ penalty with the sum of absolute values:

$$J_{\text{Lasso}}(\boldsymbol{\theta}) = \|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|_2^2 + \lambda \|\boldsymbol{\theta}\|_1 = \sum_{i=1}^n (y_i - \mathbf{x}_i^T\boldsymbol{\theta})^2 + \lambda \sum_{j=1}^p |\theta_j|$$

Because the absolute value function $|\theta_j|$ is non-differentiable at $\theta_j = 0$, Lasso has no closed-form solution and is solved numerically via coordinate descent.

### 4.1 The Geometric Diamond Argument

To understand why Lasso produces exact zeros (sparsity), consider the equivalent constrained optimization formulations:

$$\min_{\boldsymbol{\theta}} \text{RSS}(\boldsymbol{\theta}) \quad \text{subject to} \quad \begin{cases} \|\boldsymbol{\theta}\|_2^2 \le C & \text{(Ridge)} \\ \|\boldsymbol{\theta}\|_1 \le C & \text{(Lasso)} \end{cases}$$

* **Ridge ($L_2$ Ball):** The constraint boundary is a smooth sphere/circle. The elliptical contours of the RSS objective contact the circle at arbitrary smooth points, where neither coordinate is zero.
* **Lasso ($L_1$ Diamond):** The constraint boundary has sharp corners located precisely on the coordinate axes ($\theta_1 = 0$ or $\theta_2 = 0$). An expanding elliptical RSS contour contacts these sharp corners first with high probability.

Thus, Lasso performs **automatic feature selection**, driving irrelevant or redundant feature weights strictly to zero!

## 6. Andrew Ng's Empirical Machine Learning Diagnostics

When an applied machine learning model performs poorly on unseen test patients, what concrete action should an engineer take?

In Stanford CS229, Andrew Ng formalized a rigorous diagnostic methodology based on **Learning Curves** (plotting training and validation error as a function of training sample size $m$).

```{python}
#| label: fig-learning-curves
#| fig-cap: "Andrew Ng's Diagnostic Learning Curves: High Bias (left) exhibits an early high-error plateau where adding data fails; High Variance (right) exhibits a large generalization gap that narrows as training size grows."
#| code-fold: true
#| code-summary: "Generate Andrew Ng Learning Curves"
#| fig-width: 10
#| fig-height: 4.5
#| fig-align: left
#| out-width: "100%"

m_sizes = np.linspace(20, 200, 10, dtype=int)
train_err_bias, val_err_bias = [], []
train_err_var, val_err_var = [], []

for m in m_sizes:
    x_sub = x_all[:m]
    y_sub = y_all[:m]
    
    # High Bias Model (Degree 1)
    m_bias = LinearRegression().fit(x_sub.reshape(-1, 1), y_sub)
    train_err_bias.append(np.mean((y_sub - m_bias.predict(x_sub.reshape(-1, 1)))**2))
    val_err_bias.append(np.mean((y_val - m_bias.predict(x_val.reshape(-1, 1)))**2))
    
    # High Variance Model (Degree 8, unregularized)
    m_var = make_pipeline(PolynomialFeatures(8), LinearRegression()).fit(x_sub.reshape(-1, 1), y_sub)
    train_err_var.append(np.mean((y_sub - m_var.predict(x_sub.reshape(-1, 1)))**2))
    val_err_var.append(np.mean((y_val - m_var.predict(x_val.reshape(-1, 1)))**2))

fig, axes = plt.subplots(1, 2, figsize=(10, 4.5))

axes[0].plot(m_sizes, train_err_bias, 'o-', color='#1f77b4', lw=2, label='Training Loss')
axes[0].plot(m_sizes, val_err_bias, 's--', color='crimson', lw=2, label='Validation Loss')
axes[0].axhline(2.8, color='black', linestyle=':', label='High Error Plateau')
axes[0].set_title('High Bias (Underfitting): More Data Will NOT Help')
axes[0].set_xlabel('Training Sample Size $m$')
axes[0].set_ylabel('Mean Squared Error')
axes[0].legend(fontsize=8, loc='center right')
axes[0].grid(True, alpha=0.3)

axes[1].plot(m_sizes, train_err_var, 'o-', color='#1f77b4', lw=2, label='Training Loss')
axes[1].plot(m_sizes, val_err_var, 's--', color='crimson', lw=2, label='Validation Loss')
axes[1].set_title('High Variance (Overfitting): More Data Helps')
axes[1].set_xlabel('Training Sample Size $m$')
axes[1].set_ylabel('Mean Squared Error')
axes[1].set_ylim(0, 10)
axes[1].legend(fontsize=8, loc='upper right')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### 6.1 Andrew Ng's 6 Diagnostic Actions

| Diagnostic Finding | Root Pathology | Recommended Corrective Action | Why it Works |
| :--- | :--- | :--- | :--- |
| **Large Gap** ($J_{\text{val}} \gg J_{\text{train}}$) | **High Variance** | **Collect more training data ($m \uparrow$)** | Constrains high-degree flexibility |
| **Large Gap** ($J_{\text{val}} \gg J_{\text{train}}$) | **High Variance** | **Reduce number of features ($p \downarrow$)** | Reduces model degrees of freedom |
| **Large Gap** ($J_{\text{val}} \gg J_{\text{train}}$) | **High Variance** | **Increase regularization ($\lambda \uparrow$)** | Shrinks weights and conditions Gram matrix |
| **High Plateau** ($J_{\text{train}} \approx J_{\text{val}}$ both high) | **High Bias** | **Engineer polynomial / interaction features** | Enriches hypothesis space |
| **High Plateau** ($J_{\text{train}} \approx J_{\text{val}}$ both high) | **High Bias** | **Add new clinical predictors** | Provides unobserved physical signal |
| **High Plateau** ($J_{\text{train}} \approx J_{\text{val}}$ both high) | **High Bias** | **Decrease regularization ($\lambda \downarrow$)** | Relieves artificial constraints on weights |
