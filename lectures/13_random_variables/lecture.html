From Uniform to Markov Chain Monte Carlo

1. Preparation & Concept Overview

Pre-Class Preparation (Flipped Classroom)

Before coming to this lecture, please complete the following:

The Paradox of Randomness

  • The Core Question: How can a completely deterministic machine generate a “random” number?
  • Algorithmic State: Every computer action is a predictable sequence of state changes.
  • The Solution: We simulate randomness using mathematical functions that “shuffle” states.
  • Stochastic ML: Neural net weight initialization, SGD shuffling, and MCMC sampling all rely on these generators.

2. Real-World Applications

  • Crypto Failures: Netscape SSL seed prediction (1995) and Bitcoin wallet vulnerabilities (“Randstorm”, 2023).
  • Weight Initialization: Deep neural networks require non-zero random initialization (e.g. He/Glorot) to break symmetry.
  • Monte Carlo Integration: Estimating high-dimensional intractable integrals in computational physics and machine learning.

3. History & Philosophy

John von Neumann (1951)

  • “Anyone who considers arithmetical methods of producing random digits is, of course, in a state of sin.”
  • Warned about pseudo-random cycle limits.

RAND Corporation (1955)

  • Published A Million Random Digits using a physical electronic roulette wheel.

4. Theory: Summary

Recap: [Uniform distributions, CDFs, change of variables]

  • Linear Congruential Generator (LCG): \[X_{n+1} = (a X_n + c) \bmod m\]
  • Inverse Transform Sampling: \[X = F^{-1}(U), \quad U \sim \text{Unif}(0,1)\]
  • Rejection Sampling Acceptance Condition: \[U \le \frac{p(Y)}{M \cdot q(Y)}, \quad Y \sim q(y)\]
  • Metropolis-Hastings Acceptance Ratio: \[\alpha(x, x') = \min\left(1, \frac{\tilde{p}(x') q(x|x')}{\tilde{p}(x) q(x'|x)}\right)\]
  • Note: Detailed proofs of the Box-Muller polar transform and detailed balance for MCMC are provided in the companion derivation notes / whiteboard cheat sheet.

5. Implementations and Illustrations

Metropolis-Hastings MCMC implementation:

import numpy as np

# Metropolis-Hastings for target p(x) ~ exp(-0.5 * x^2)
def metropolis_hastings(n_samples=5000, width=0.5):
    samples = np.zeros(n_samples)
    curr = 0.0
    for i in range(1, n_samples):
        prop = curr + np.random.normal(0, width)
        ratio = np.exp(-0.5 * prop**2) / np.exp(-0.5 * curr**2)
        if np.random.rand() < min(1.0, ratio):
            curr = prop
        samples[i] = curr
    return samples

6. Outlook & Optional Extensions

Key Takeaways

  • Pseudorandom generators provide reproducible stochasticity; MCMC allows sampling complex unnormalized posteriors.

Optional Extensions

  • Gibbs Sampling: Special case sampling variables one-by-one from conditional distributions (Bayesian inference).
  • Hamiltonian Monte Carlo (HMC): Uses gradients of log-probability to navigate high dimensions efficiently.
  • Suggested Readings:
    • Christopher M. Bishop (2006), Pattern Recognition and Machine Learning, Chapter 11.
