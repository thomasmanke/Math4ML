import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (
    confusion_matrix, roc_curve, roc_auc_score,
    precision_recall_curve, average_precision_score
)

sns.set_theme(style="whitegrid")
FIGSIZE = (10, 4.5)

# Generate realistic clinical cohort (n = 150 patients)
np.random.seed(42)
n = 150
glucose = np.random.uniform(70, 180, n)  # Fasting Plasma Glucose (mg/dL)

# Latent log-odds: z = -8.5 + 0.07 * Glucose (crossover p=0.5 at ~121.4 mg/dL)
z_true = -8.5 + 0.07 * glucose
p_true = 1.0 / (1.0 + np.exp(-z_true))
y = (np.random.uniform(0, 1, n) < p_true).astype(int)

# Fit unregularized Logistic Regression model
model = LogisticRegression(C=1e9, solver="lbfgs")
model.fit(glucose.reshape(-1, 1), y)
p_pred = model.predict_proba(glucose.reshape(-1, 1))[:, 1]

1. Deviance

In linear regression, a model fit can be charcaterized by the Residual Sum of Squares:

\[ RSS(\hat{\theta}) = \sum_{i=1}^n (y_i - \hat{y}_i)^2 \ge 0 \]

For binary classification, \(y_i \in \{0, 1\}\), squared residuals are inadequate because the error terms are Bernoulli and the conditional variance is heteroscedastic: \(\text{Var}[Y \mid X=x] = p(x)(1 - p(x))\).

The corresponding binary cross-entropy loss, or equivalently their deviance \(D\), can be used as a measure of goodness of fit:

\[ D(\hat{\theta}) = 2 n \times L_\text{BCE} = -2 \sum_{i=1}^n \left[ y_i \ln \hat{p}_i + (1 - y_i) \ln(1 - \hat{p}_i) \right] \ge 0 \]

Apart from the fitted model, we can also define two baseline models:

  1. Saturated Model. A perfect fit that captures all individual fluctuations.

\[ \hat{p}_i = y_i \implies D(\text{saturated})=0 \]

  1. Null Model. Ignore all predictors \(X\), use sample prevalence \(\bar{p}\) for \(k\) positive cases in a cohort of size \(n\).

\[ \hat{p}_i = \bar{p} = k/n \implies D(\text{null}) = -2 \left[ k \ln(\bar{p}) + (n - k) \ln(1 - \bar{p}) \right] \gt 0 \]

The reduction in deviance, \(\Delta D = D(\text{null}) - D(\hat{\theta})\), plays the role of the explained sum of squares, \(ESS = TSS - RSS\), in ordinary least squares.

We can also define a pseudo-\(R^2\) metric:

\[ R^2 = \frac{\Delta D}{D(\text{null})} = 1 - \frac{D(\hat{\theta})}{D(\text{null})} \]

2. Decisions & Confusions

2.1 Decision Thresholding

A fitted logistic model outputs continuous conditional probabilities \(\hat{p} = P(Y = 1 \mid X=x) \in (0, 1)\). However, medical interventions and decisions require a decision threshold \(\tau\):

\[\hat{y} = \begin{cases} 1 & \text{if } \hat{p} \ge \tau \\ 0 & \text{if } \hat{p} < \tau \end{cases}\]

Plot Logistic Sigmoid with Decision Threshold 
theta_0 = model.intercept_[0]
theta_1 = model.coef_[0, 0]
crossover_glucose = -theta_0 / theta_1

x_grid = np.linspace(65, 185, 300)
p_grid = 1.0 / (1.0 + np.exp(-(theta_0 + theta_1 * x_grid)))

fig, ax = plt.subplots(figsize=(10, 4.5))

# Shaded decision regions
ax.axvspan(65, crossover_glucose, color="#1b9e77", alpha=0.10, label="Predicted Healthy (ŷ = 0)")
ax.axvspan(crossover_glucose, 185, color="#d95f02", alpha=0.10, label="Predicted Diabetic (ŷ = 1)")

# Fitted Sigmoid
ax.plot(x_grid, p_grid, color="#2b5c8f", lw=2.5, label="Fitted P(Diabetes | Glucose)")

# Patient Observations
ax.scatter(glucose[y == 0], y[y == 0], color="#1b9e77", edgecolors="k", s=40, alpha=0.85, label="Actual Healthy (y=0)")
ax.scatter(glucose[y == 1], y[y == 1], color="#d95f02", edgecolors="k", s=40, alpha=0.85, label="Actual Diabetic (y=1)")

# Threshold markers at tau = 0.5
tau = 0.5
ax.axhline(tau, color="gray", linestyle="--", lw=1.5, label=f"Threshold τ = {tau}")
ax.axvline(crossover_glucose, color="#d62728", linestyle=":", lw=1.8, label=f"Decision Cutoff ({crossover_glucose:.1f} mg/dL)")

ax.set_title("Logistic Probability Curve and Decision Thresholding", fontsize=12, pad=10)
ax.set_xlabel("Fasting Plasma Glucose (mg/dL)", fontsize=11)
ax.set_ylabel("Predicted Probability P(y = 1 | x)", fontsize=11)
ax.set_ylim(-0.05, 1.05)
ax.legend(loc="upper left", frameon=True)
ax.grid(True, linestyle=":", alpha=0.5)

plt.tight_layout()
plt.show()

2.2 Confusion Matrix

Comparing discrete predictions \(\hat{y} \in \{0, 1\}\) against actual ground truth \(y \in \{0, 1\}\) partitions all outcomes into four diagnostic quadrants:

  • True Positives TP
  • True Negatives TN
  • False Positives FP
  • False Negatives FN
Plot Confusion Matrix Heatmap 
tau = 0.5
y_pred = (p_pred >= tau).astype(int)
cm = confusion_matrix(y, y_pred)

2.3 Diagnostic Metrics

There are only four numbers, but a host of other numbers and confusion metrics can be defined from those:

Metric Name Equation Clinical Meaning
Accuracy \(\frac{\text{TP} + \text{TN}}{\text{Total}}\) Overall fraction of correct diagnostic classifications across all patients.
Specificity (TNR) \(\frac{\text{TN}}{\text{TN} + \text{FP}}\) Fraction of healthy individuals correctly identified and cleared.
Sensitivity (Recall / TPR) \(\frac{\text{TP}}{\text{TP} + \text{FN}}\) Fraction of all sick patients successfully detected by the screening test.
Precision (PPV) \(\frac{\text{TP}}{\text{TP} + \text{FP}}\) Probability that a patient flagged positive by the test is truly diseased.
\(F_1\)-Score \(2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}\) Harmonic mean balancing Precision and Recall.

see also: https://en.wikipedia.org/wiki/Confusion_matrix

ImportantAccuracy versus Costs

In medical screening, diagnostic costs are often asymmetric:

  • Accuracy Fallacy: When a disease is rare (e.g., 2% prevalence), a naive classifier predicting “healthy” for every patient achieves 98% accuracy yet fails to detect a single sick patient (\(\text{Sensitivity} = 0\%\)).

  • Cost of False Negative (\(C_{\text{FN}}\)): An undetected sick patient goes untreated, leading to preventable complications or mortality.

  • Cost of False Positive (\(C_{\text{FP}}\)): A healthy patient receives an unnecessary follow-up blood test, causing minor anxiety and cost.

Because \(C_{\text{FN}} \gg C_{\text{FP}}\), clinicians deliberately lower the threshold (e.g., \(\tau = 0.20\)) to catch more sick patients, consciously accepting a higher false-alarm rate.

3. ROC and PR Curves

Rather than evaluating a single fixed threshold \(\tau\), sweeping \(\tau\) continuously across \([0, 1]\) traces out the complete operational trade-off across all potential operating points.

  • The Receiver Operating Characteristic (ROC) curve plots True Positive Rate (Sensitivity) against False Positive Rate (\(1 - \text{Specificity}\)).
  • The Precision-Recall (PR) curve plots Precision against Recall, which is particularly informative when evaluating imbalanced or rare-prevalence cohorts.
Generate Side-by-Side ROC and PR Curves 
fpr, tpr, roc_thresholds = roc_curve(y, p_pred)
auc_val = roc_auc_score(y, p_pred)

prec, rec, pr_thresholds = precision_recall_curve(y, p_pred)
ap_val = average_precision_score(y, p_pred)

# Exact operational operating point at threshold tau = 0.5
tau_05 = 0.5
y_pred_05 = (p_pred >= tau_05).astype(int)
tn_05, fp_05, fn_05, tp_05 = confusion_matrix(y, y_pred_05).ravel()

tpr_05 = tp_05 / (tp_05 + fn_05)   # True Positive Rate = Sensitivity = Recall
fpr_05 = fp_05 / (fp_05 + tn_05)   # False Positive Rate = 1 - Specificity
prec_05 = tp_05 / (tp_05 + fp_05)  # Precision = Positive Predictive Value
rec_05 = tpr_05                    # Identically equal to True Positive Rate

fig, axes = plt.subplots(1, 2, figsize=(10, 4.5))

# Panel 1: ROC Curve
axes[0].plot(fpr, tpr, color="#1f77b4", lw=2.5, label=f"ROC Curve (AUC = {auc_val:.3f})")
axes[0].plot([0, 1], [0, 1], "k--", lw=1.5, label="Random Guessing (AUC = 0.500)")
axes[0].scatter(fpr_05, tpr_05, color="#d62728", s=80, zorder=5,
                label=f"τ = 0.5 (FPR={fpr_05:.2f}, TPR={tpr_05:.2f})")

axes[0].set_title("Receiver Operating Characteristic (ROC)", fontsize=12, pad=10)
axes[0].set_xlabel("False Positive Rate (1 - Specificity)", fontsize=11)
axes[0].set_ylabel("True Positive Rate (Sensitivity / Recall)", fontsize=11)
axes[0].legend(loc="lower right", frameon=True)
axes[0].grid(True, linestyle=":", alpha=0.5)

# Panel 2: Precision-Recall Curve
axes[1].plot(rec, prec, color="#2ca02c", lw=2.5, label=f"PR Curve (AP = {ap_val:.3f})")
baseline_prev = np.mean(y)
axes[1].axhline(baseline_prev, color="gray", linestyle="--", lw=1.5, label=f"Baseline Prevalence ({baseline_prev:.2f})")
axes[1].scatter(rec_05, prec_05, color="#d62728", s=80, zorder=5,
                label=f"τ = 0.5 (Rec={rec_05:.2f}, Prec={prec_05:.2f})")

axes[1].set_title("Precision-Recall Curve", fontsize=12, pad=10)
axes[1].set_xlabel("Recall (Sensitivity / True Positive Rate)", fontsize=11)
axes[1].set_ylabel("Precision (Positive Predictive Value)", fontsize=11)
axes[1].legend(loc="lower left", frameon=True)
axes[1].grid(True, linestyle=":", alpha=0.5)

plt.tight_layout()
plt.show()
  • Area Under the ROC Curve (AUC): \(\text{AUC} \approx 0.90\) summarizes diagnostic discrimination across all false-positive rates, substantially exceeding the random guessing baseline of \(0.50\).
  • Average Precision (AP): \(\text{AP} \approx 0.92\) measures the area under the Precision-Recall curve (\(\int_0^1 P(R) \, dR\)), summarizing positive predictive performance across all recall levels. Unlike ROC-AUC, the random-guessing baseline for AP is the sample prevalence (\(\bar{p} \approx 0.51\)), with a perfect test reaching \(\text{AP} = 1.0\).

```{python}
axes[1].set_ylabel("Precision (Positive Predictive Value)", fontsize=11)
axes[1].legend(loc="lower left", frameon=True)
axes[1].grid(True, linestyle=":", alpha=0.5)

plt.tight_layout()
plt.show()
```

* **Area Under the ROC Curve (AUC)**: $\text{AUC} \approx 0.90$ summarizes diagnostic discrimination across all false-positive rates, substantially exceeding the random guessing baseline of $0.50$.
* **Average Precision (AP)**: $\text{AP} \approx 0.92$ measures the area under the Precision-Recall curve ($\int_0^1 P(R) \, dR$), summarizing positive predictive performance across all recall levels. Unlike ROC-AUC, the random-guessing baseline for AP is the sample prevalence ($\bar{p} \approx 0.51$), with a perfect test reaching $\text{AP} = 1.0$.

## 4. Review

| Concept | Linear Regression | Logistic Regression |
| :--- | :--- | :--- |
| **Target Variable** | Continuous $y \in \mathbb{R}$ | Binary $y \in \{0, 1\}$ |
| **Residual Metric** | $RSS = \sum (y_i - \hat{y}_i)^2$ | $D = -2 \ln L(\hat{\theta}) = 2n \times \text{BCE}$ |
| **Baseline Benchmark** | Total Sum of Squares ($TSS$) | Null Deviance $D(\text{null})$ |
| **Explanatory Gain** | $ESS = TSS - RSS$ | $\Delta D = D(\text{null}) - D(\hat{\theta})$ |
| **Operational Metric** | $R^2$, RMSE | Confusion Matrix, Sensitivity, Specificity, AUC, ... |
