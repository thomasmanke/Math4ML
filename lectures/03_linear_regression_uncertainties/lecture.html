Linear Regression with scikit-learn

In previous lectures, linear regression was developed from first principles using NumPy matrix algebra.

Here, we introduce the standard workflow with scikit-learn (sklearn.linear_model.LinearRegression). Scikit-learn provides an expressive, consistent object-oriented API for machine learning in Python:

  1. Instantiate: model = LinearRegression() sets up the model.
  2. Fit: model.fit(x, y) solves Normal Equations.
  3. Inspect Parameters: Access fitted parameters via model.intercept_ and model.coef_
  4. Generate Predictions: model.predict(x).
Linear Regression with scikit-learn 
# Explicit import for model fitting
from sklearn.linear_model import LinearRegression

VAR1 = "insulin"
VAR2 = "glucose"

# Prepare data: scikit-learn requires a 2D feature matrix X (n_samples, n_features) and target y

print("Model equation:")

y_hat = model.predict(x)

Parameter Uncertainties

Sampling fluctuations (measured by \(\sigma^2\)) induce uncertainty in the parameter estimates \(\hat{\boldsymbol{\theta}}\):

\[ \operatorname{Cov}(\hat{\boldsymbol{\theta}}) = \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1} \]

\[ \sigma^2 \approx \hat{\sigma}^2 = \frac{RSS}{n - p} \]

NoteMathematical Derivation: Parameter Covariance

A model is a mapping from \(\mathbf{x}\) to \(\mathbf{y}\). \[ \mathbf{y} = f(\mathbf{x}) + \boldsymbol{\epsilon} \] In general, \(\boldsymbol{\epsilon}\) captures both systematic errors (e.g. model misspecification) and irreducible measurement errors.

Let’s assume \(\boldsymbol{\epsilon}\) contains only independent, homoscedastic measurement errors for \(n\) observations (samples): \[ \operatorname{Cov}(\mathbf{y} \mid \mathbf{X}) = \operatorname{Cov}(\boldsymbol{\epsilon} \mid \mathbf{X}) = \sigma^2 \mathbf{I}_n \]

For linear regression, the OLS parameter vector \(\hat{\boldsymbol{\theta}}\) can be obtained as a linear mapping of the target vector \(\mathbf{y}\): \[ \hat{\boldsymbol{\theta}} = \mathbf{A}\mathbf{y} \qquad \text{where } \mathbf{A} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \in \mathbb{R}^{p \times n} \] Applying the bilinear property of covariance: \[ \operatorname{Cov}(\hat{\boldsymbol{\theta}} \mid \mathbf{X}) = \operatorname{Cov}(\mathbf{A}\mathbf{y} \mid \mathbf{X}) = \mathbf{A} \operatorname{Cov}(\mathbf{y} \mid \mathbf{X}) \mathbf{A}^T \] This reduces to: \[ \mathbf{A} (\sigma^2 \mathbf{I}_n) \mathbf{A}^T = \sigma^2 \mathbf{A}\mathbf{A}^T = \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} = \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1} \]

We estimate the unknown scalar observation variance \(\sigma^2\) from the sample residuals \(\mathbf{e} = \mathbf{y} - \mathbf{X}\hat{\boldsymbol{\theta}}\): \[ \sigma^2 \approx \hat{\sigma}^2 = \frac{\mathbf{e}^T \mathbf{e}}{n - p} = \frac{RSS}{n - p} \]

Parameter Covariance Matrix Heatmap 
# 1. Construct design matrix including intercept column of ones
X_design = np.column_stack([np.ones(len(x)), x])
n, p = X_design.shape

# 2. Residual variance estimate sigma^2_hat
residuals = y - model.predict(x)
sigma2_hat = np.sum(residuals**2) / (n - p)

# 3. Covariance matrix: Cov(theta_hat) = sigma2_hat * (X^T X)^(-1)

We can quantify parameter uncertainty using a confidence interval:

\[ \hat{\theta}_j \pm c \cdot SE(\hat{\theta}_j) \]

The multiplier \(c\) is arbitrary and corresponds to the desired confidence level (\(c=1.96\) for a 95% interval under standard normal approximation, or \(t_{n-p, 1-\alpha/2}\) under the Student’s \(t\)-distribution).

Data in \(n\) Dimensions

We can express the data vector \(\mathbf{y}\) as a step-by-step progression:

  1. Base Model (The Mean): \(\bar{\mathbf{y}} = \bar{y}\mathbf{1}\), the horizontal benchmark where no input features are used.
  2. Improved Model (The Linear Fit): Moving from the base model \(\bar{y}\mathbf{1}\) to the full prediction \(\hat{\mathbf{y}} = \mathbf{X}\hat{\boldsymbol{\theta}}\) captures the improvement provided by the input features.
  3. Observation Error: Moving from the prediction \(\hat{\mathbf{y}}\) to the actual observation \(\mathbf{y}\) represents the remaining unexplained error.

In vector notation: \[ \mathbf{y} = \underbrace{\bar{y}\mathbf{1}}_{\text{Base model}} + \underbrace{(\hat{\mathbf{y}} - \bar{y}\mathbf{1})}_{\text{Explained improvement}} + \underbrace{(\mathbf{y} - \hat{\mathbf{y}})}_{\text{Unexplained error}} \]

Subtracting the baseline mean vector \(\bar{y}\mathbf{1}\) from both sides centers the decomposition around the null model:

\[ \underbrace{(\mathbf{y} - \bar{y}\mathbf{1})}_{\text{Total deviation}} = \underbrace{(\hat{\mathbf{y}} - \bar{y}\mathbf{1})}_{\text{Explained deviation}} + \underbrace{(\mathbf{y} - \hat{\mathbf{y}})}_{\text{Residual deviation}} \]

Pythagoras in \(\mathbb{R}^n\)

Recall that OLS minimizes \(\|\mathbf{e}\|^2\) by projecting \(\mathbf{y}\) orthogonally onto the model column space \(\operatorname{col}(\mathbf{X})\). The residual vector \(\mathbf{e} = \mathbf{y} - \hat{\mathbf{y}}\) is perpendicular to every column in \(\mathbf{X}\):

\[ \mathbf{X}^T \mathbf{e} = \mathbf{X}^T (\mathbf{y} - \hat{\mathbf{y}}) = \mathbf{0} \]

Because both \(\hat{\mathbf{y}}\) and the vector \(\mathbf{1}\) lie in \(\operatorname{col}(\mathbf{X})\), their difference \((\hat{\mathbf{y}} - \bar{y}\mathbf{1})\) also lies entirely in \(\operatorname{col}(\mathbf{X})\). Consequently:

\[ (\hat{\mathbf{y}} - \bar{y}\mathbf{1})^T (\mathbf{y} - \hat{\mathbf{y}}) = 0 \]

The explained vector and the residual vector meet at a right angle in \(\mathbb{R}^n\).

Applying the Pythagorean Theorem to this right triangle:

\[ \begin{aligned} \|\mathbf{y} - \bar{y}\mathbf{1}\|^2 &= \|\hat{\mathbf{y}} - \bar{y}\mathbf{1}\|^2 + \|\mathbf{y} - \hat{\mathbf{y}}\|^2 \\ \\ TSS &= ESS + RSS \\ \\ (n - 1) &= (p - 1) + (n - p) \end{aligned} \]

Component Vector in \(\mathbb{R}^n\) Sum of Squares Formula df Mean Square
\(MS = SS / df\)
Total
(\(TSS\))		 \(\mathbf{y} - \bar{y}\mathbf{1}\) \(\sum_{i=1}^n (y_i - \bar{y})^2\) \(n - 1\) \(s_y^2 = \frac{TSS}{n - 1}\)
Explained
(\(ESS\))		 \(\hat{\mathbf{y}} - \bar{y}\mathbf{1}\) \(\sum_{i=1}^n (\hat{y}_i - \bar{y})^2\) \(p - 1\) \(MS_{\text{exp}} = \frac{ESS}{p - 1}\)
Residual
(\(RSS\))		 \(\mathbf{y} - \hat{\mathbf{y}}\) \(\sum_{i=1}^n (y_i - \hat{y}_i)^2\) \(n - p\) \(MS_{\text{res}} = \frac{RSS}{n - p} = \hat{\sigma}^2\)
  • Total Degrees of Freedom (\(n - 1\)): The observation vector \(\mathbf{y}\) lives in \(\mathbb{R}^n\). Subtracting the sample mean imposes \(1\) linear constraint (\(\sum_{i=1}^n (y_i - \bar{y}) = 0\)), leaving \(n - 1\) independent directions of variation.
  • Explained Degrees of Freedom (\(p - 1\)): The model subspace \(\operatorname{col}(\mathbf{X})\) has dimension \(p\). Because the constant intercept baseline already occupies \(1\) dimension (\(\operatorname{span}(\mathbf{1})\)), the remaining \(p - 1\) slope features add \(p - 1\) independent degrees of freedom (\(1\) dof for simple linear regression).
  • Residual Degrees of Freedom (\(n - p\)): The OLS normal equations force the residuals to be strictly orthogonal to all \(p\) columns of \(\mathbf{X}\) (\(\mathbf{X}^T\mathbf{e} = \mathbf{0}\)). These \(p\) linear constraints confine the residual vector to the orthogonal complement subspace \(\operatorname{col}(\mathbf{X})^\perp\) of dimension \(n - p\).

Fraction of Explained Variation (\(R^2\))

The Coefficient of Determination (\(R^2\)) measures the proportion of total variation in \(y\) successfully explained by the linear model:

\[ R^2 = \frac{ESS}{TSS} = 1 - \frac{RSS}{TSS} = 1 - \frac{\sum_{i=1}^n (y_i - \hat{y}_i)^2}{\sum_{i=1}^n (y_i - \bar{y})^2} \]

\(R^2\) also relates to the angle \(\phi\) of triangle \(\triangle(\bar{y}\mathbf{1}, \hat{\mathbf{y}}, \mathbf{y})\) at vertex \(\bar{y}\mathbf{1}\): \[ \cos(\phi) = \frac{\|\hat{\mathbf{y}} - \bar{y}\mathbf{1}\|}{\|\mathbf{y} - \bar{y}\mathbf{1}\|} = \sqrt{\frac{ESS}{TSS}} \implies \cos^2(\phi) = R^2 \]

  • If the model explains all variability (\(RSS = 0\)): \[ESS = TSS \implies R^2 = 1 \to \phi = 0^\circ\]

  • If the model performs no better than the constant mean (\(ESS = 0\)): \[RSS = TSS \implies R^2 = 0 \to \phi = 90^\circ\]

Relative Improvement by the Model (\(F\)-statistic)

To assess the relative improvement achieved by the model (\(ESS = TSS - RSS\)), we compare the explained sum of squares (\(ESS\)) to the unexplained residual noise variance (\(RSS\)).

Since both quantities have different degrees of freedom we divide each term by its respective degrees of freedom to compare Mean Squares. This ratio is called the \(F\)-statistics:

\[ F = \frac{MS_{\text{exp}}}{MS_{\text{res}}} = \frac{ESS / (p - 1)}{RSS / (n - p)} \]

A large \(F\)-statistic (\(F > 1\)) indicates large improvements over the baseline model.

NoteCheck Regression Assumptions

\[ \epsilon_i \sim \mathcal{N}(0, \sigma^2) \]

  1. Normality: Residuals are approximately normally distributed around zero.
  2. Independence: Residuals are independent across patients.
  3. Homoscedasticity: Residual variance is constant across predictor values.

Prediction Uncertainties

Uncertainties in model parameters directly propagate into uncertainties in model predictions.

Confidence Intervals

For a new input query, we define the column vector \(\mathbf{x}_0 = (1, x_{\text{new}})^T\) containing the constant \(1\) for the intercept and the predictor value \(x_{\text{new}}\).

The leverage (or variance multiplier) for \(\mathbf{x}_0\) is given by:

\[ h(\mathbf{x}_0) = \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0 = \frac{1}{n} + \frac{(x_{\text{new}} - \bar{x})^2}{\sum_{i=1}^n (x_i - \bar{x})^2} \]

NoteConnection to the Full Hat Matrix \(\mathbf{H}\)

The leverage scalar \(h(\mathbf{x}_0)\) quantifies how far any input \(\mathbf{x}_0\) lies from the center of the training data. For an in-sample observation \(\mathbf{x}_i\), \(h(\mathbf{x}_i) = H_{ii}\) is precisely the \(i\)-th diagonal element of the full \(n \times n\) Hat Matrix: \[\mathbf{H} = \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \qquad ( \hat{\mathbf{y}} = \mathbf{H}\mathbf{y})\] Diagonal elements \(H_{ii} \in [1/n, 1]\) measure how strongly observation \(y_i\) influences its own fitted prediction \(\hat{y}_i\).

Confidence interval for the expected response \(\mathbb{E}[y \mid \mathbf{x}_0]\):

\[ \hat{y}(\mathbf{x}_0) \pm t_{n-p, 1-\alpha/2} \cdot \hat{\sigma} \sqrt{h(\mathbf{x}_0)} \]

Python Implementation 
# Make predictions on training data with confidence interval
X_pred = x
y_pred = model.predict(X_pred)

n = len(y) # observations
p = X_pred.shape[1] + 1 # parameters (2)

# Calculate residuals and standard error
eps = y - y_pred
sig = np.sqrt(np.sum(eps**2) / (n - p))

# Calculate confidence interval (82% level)
confidence_level = 0.82
t_val = stats.t.ppf((1 + confidence_level) / 2, n - p)
h = 1/n + (X_pred - X_pred.mean())**2 / np.sum((X_pred - X_pred.mean())**2)
se = sig * np.sqrt(h)

lwr = y_pred - t_val * se
upr = y_pred + t_val * se

# Display first few predictions
pred_df = pd.DataFrame({
    'insulin': X_pred.flatten()[:5],
    'fit': y_pred.flatten()[:5],
    'lwr': lwr.flatten()[:5],

Prediction Intervals

The variation of individual patient observations is clearly larger than suggested by the confidence interval shown above.

It is important to remember that in our linear model there are two distinct components of variation:

\[ \|\mathbf{y} - \bar{y}\mathbf{1}\|^2 = \|\mathbf{y} - \hat{\mathbf{y}}\|^2 + \|\hat{\mathbf{y}} - \bar{y}\mathbf{1}\|^2 \]

  • Variance explained by the linear model: \(\|\hat{\mathbf{y}} - \bar{y}\mathbf{1}\|^2\) where \(\hat{\mathbf{y}} = \mathbf{X} \hat{\boldsymbol{\theta}}\). Errors in parameter estimation induce uncertainty in the estimated mean \(\hat{y}_0\).
  • Unexplained observation noise: \(\|\mathbf{y} - \hat{\mathbf{y}}\|^2 = \|\boldsymbol{\epsilon}\|^2\), where each individual patient exhibits natural physiological deviation \(\epsilon \sim \mathcal{N}(0, \sigma^2)\).

To capture where a new individual patient’s measurement will fall, we must include both parameter uncertainty and individual measurement noise:

\[ h(\mathbf{x}_0) = \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0 \]

\[ \hat{y}(\mathbf{x}_0) \pm t_{n-p, 1-\alpha/2} \cdot \hat{\sigma} \sqrt{1 + h(\mathbf{x}_0)} \]

Python Implementation 
# Prediction intervals with full variability
prediction_level = 0.82
t_val_pi = stats.t.ppf((1 + prediction_level) / 2, n - p)

# Prediction interval includes both model uncertainty (h) and residual variance (1)
se_pi = sig * np.sqrt(1 + h)

lwr_pi = y_pred - t_val_pi * se_pi
upr_pi = y_pred + t_val_pi * se_pi

plt.figure(figsize=FIGSIZE)
plt.scatter(X_pred, y, alpha=0.4, color='#1f77b4', label="Data") 

# Sort for plotting lines
sort_idx = np.argsort(X_pred.flatten())

NoteNotice

The prediction interval covers the broader scatter of future individual observations. Even with infinite data (\(n \to \infty, h \to 0\)), the prediction interval never collapses to zero because irreducible physiological noise \(\sigma\) remains.

## Parameter Uncertainties

Sampling fluctuations (measured by $\sigma^2$) induce uncertainty in the parameter estimates $\hat{\boldsymbol{\theta}}$:

$$
\operatorname{Cov}(\hat{\boldsymbol{\theta}}) = \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1}
$$

$$
\sigma^2 \approx \hat{\sigma}^2 = \frac{RSS}{n - p}
$$


::: {.callout-note collapse="true"}
#### Mathematical Derivation: Parameter Covariance

A model is a mapping from $\mathbf{x}$ to $\mathbf{y}$.
$$
\mathbf{y} = f(\mathbf{x}) + \boldsymbol{\epsilon}
$$
In general, $\boldsymbol{\epsilon}$ captures both **systematic** errors (e.g. model misspecification) and **irreducible** measurement errors.

Let's assume $\boldsymbol{\epsilon}$ contains only independent, homoscedastic measurement errors for $n$ observations (samples):
$$
\operatorname{Cov}(\mathbf{y} \mid \mathbf{X}) = \operatorname{Cov}(\boldsymbol{\epsilon} \mid \mathbf{X}) = \sigma^2 \mathbf{I}_n
$$

For linear regression, the OLS parameter vector $\hat{\boldsymbol{\theta}}$ can be obtained as a linear mapping of the target vector $\mathbf{y}$:
$$
\hat{\boldsymbol{\theta}} = \mathbf{A}\mathbf{y} \qquad \text{where } \mathbf{A} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \in \mathbb{R}^{p \times n}
$$
Applying the bilinear property of covariance:
$$
\operatorname{Cov}(\hat{\boldsymbol{\theta}} \mid \mathbf{X}) = \operatorname{Cov}(\mathbf{A}\mathbf{y} \mid \mathbf{X}) = \mathbf{A} \operatorname{Cov}(\mathbf{y} \mid \mathbf{X}) \mathbf{A}^T
$$
This reduces to:
$$
\mathbf{A} (\sigma^2 \mathbf{I}_n) \mathbf{A}^T = \sigma^2 \mathbf{A}\mathbf{A}^T = \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} = \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1}
$$

We estimate the unknown scalar observation variance $\sigma^2$ from the sample residuals $\mathbf{e} = \mathbf{y} - \mathbf{X}\hat{\boldsymbol{\theta}}$:
$$
\sigma^2 \approx \hat{\sigma}^2 = \frac{\mathbf{e}^T \mathbf{e}}{n - p} = \frac{RSS}{n - p}
$$

:::




```{python}
#| label: cov_parameters_heatmap
#| code-fold: true
#| code-summary: "Parameter Covariance Matrix Heatmap"
#| fig-cap: 'Diagonal Elements: Variance of each parameter ($SE(\hat{\theta}_j)^2$). Off-Diagonal Elements: Covariance between parameters ($\operatorname{Cov}(\hat{\theta}_j, \hat{\theta}_k)$).'

# 1. Construct design matrix including intercept column of ones
X_design = np.column_stack([np.ones(len(x)), x])
n, p = X_design.shape

# 2. Residual variance estimate sigma^2_hat
residuals = y - model.predict(x)
sigma2_hat = np.sum(residuals**2) / (n - p)

# 3. Covariance matrix: Cov(theta_hat) = sigma2_hat * (X^T X)^(-1)
gram_inv = np.linalg.inv(X_design.T @ X_design)
cov = sigma2_hat * gram_inv

param_labels = [r"$\theta_0$ (Intercept)", r"$\theta_1$ (Slope)"]
cov_df = pd.DataFrame(cov, index=param_labels, columns=param_labels)


# Visual Heatmap of the Covariance Matrix
fig, ax = plt.subplots(figsize=(6, 4.5))
sns.heatmap(
    cov_df,
    annot=True,
    fmt=".4g",
    cmap="RdBu_r",
    center=0,
    cbar_kws={'label': 'Covariance'},
    ax=ax
)
ax.set_title(r"Parameter Covariance: $\mathrm{Cov}(\hat{\boldsymbol{\theta}})$", fontsize=12)
plt.tight_layout()
plt.show()
```

We can quantify parameter uncertainty using a **confidence interval**:

$$
\hat{\theta}_j \pm c \cdot SE(\hat{\theta}_j)
$$

The multiplier $c$ is arbitrary and corresponds to the desired confidence level ($c=1.96$ for a 95% interval under standard normal approximation, or $t_{n-p, 1-\alpha/2}$ under the Student's $t$-distribution).

### Data in $n$ Dimensions

![Geometric Decomposition in $\mathbb{R}^n$: $\mathbf{y} = \bar{y}\mathbf{1} + (\hat{\mathbf{y}} - \bar{y}\mathbf{1}) + (\mathbf{y} - \hat{\mathbf{y}})$](images/sum_of_squares.jpg){width="90%" fig-align="center"}

We can express the data vector $\mathbf{y}$ as a step-by-step progression:

1. **Base Model (The Mean)**: $\bar{\mathbf{y}} = \bar{y}\mathbf{1}$, the horizontal benchmark where no input features are used.
2. **Improved Model (The Linear Fit)**: Moving from the base model $\bar{y}\mathbf{1}$ to the full prediction $\hat{\mathbf{y}} = \mathbf{X}\hat{\boldsymbol{\theta}}$ captures the improvement provided by the input features.
3. **Observation Error**: Moving from the prediction $\hat{\mathbf{y}}$ to the actual observation $\mathbf{y}$ represents the remaining unexplained error.

In vector notation:
$$
\mathbf{y} = \underbrace{\bar{y}\mathbf{1}}_{\text{Base model}} + \underbrace{(\hat{\mathbf{y}} - \bar{y}\mathbf{1})}_{\text{Explained improvement}} + \underbrace{(\mathbf{y} - \hat{\mathbf{y}})}_{\text{Unexplained error}}
$$

Subtracting the baseline mean vector $\bar{y}\mathbf{1}$ from both sides centers the decomposition around the null model:

$$
\underbrace{(\mathbf{y} - \bar{y}\mathbf{1})}_{\text{Total deviation}} = \underbrace{(\hat{\mathbf{y}} - \bar{y}\mathbf{1})}_{\text{Explained deviation}} + \underbrace{(\mathbf{y} - \hat{\mathbf{y}})}_{\text{Residual deviation}}
$$

#### Pythagoras in $\mathbb{R}^n$

Recall that OLS minimizes $\|\mathbf{e}\|^2$ by projecting $\mathbf{y}$ **orthogonally** onto the model column space $\operatorname{col}(\mathbf{X})$. The residual vector $\mathbf{e} = \mathbf{y} - \hat{\mathbf{y}}$ is perpendicular to every column in $\mathbf{X}$:

$$
\mathbf{X}^T \mathbf{e} = \mathbf{X}^T (\mathbf{y} - \hat{\mathbf{y}}) = \mathbf{0}
$$

Because both $\hat{\mathbf{y}}$ and the vector $\mathbf{1}$ lie in $\operatorname{col}(\mathbf{X})$, their difference $(\hat{\mathbf{y}} - \bar{y}\mathbf{1})$ also lies entirely in $\operatorname{col}(\mathbf{X})$. Consequently:

$$
(\hat{\mathbf{y}} - \bar{y}\mathbf{1})^T (\mathbf{y} - \hat{\mathbf{y}}) = 0
$$

The explained vector and the residual vector meet at a **right angle** in $\mathbb{R}^n$. 

Applying the **Pythagorean Theorem** to this right triangle:

$$
\begin{aligned}
\|\mathbf{y} - \bar{y}\mathbf{1}\|^2 &= \|\hat{\mathbf{y}} - \bar{y}\mathbf{1}\|^2 + \|\mathbf{y} - \hat{\mathbf{y}}\|^2 \\ \\
TSS &= ESS + RSS \\ \\
(n - 1) &= (p - 1) + (n - p)
\end{aligned}
$$

| Component | Vector in $\mathbb{R}^n$ | Sum of Squares Formula | df | Mean Square<br>$MS = SS / df$ |
| :--- | :--- | :--- | :---: | :--- |
| **Total**<br>($TSS$) | $\mathbf{y} - \bar{y}\mathbf{1}$ | $\sum_{i=1}^n (y_i - \bar{y})^2$ | $n - 1$ | $s_y^2 = \frac{TSS}{n - 1}$ |
| **Explained**<br>($ESS$) | $\hat{\mathbf{y}} - \bar{y}\mathbf{1}$ | $\sum_{i=1}^n (\hat{y}_i - \bar{y})^2$ | $p - 1$ | $MS_{\text{exp}} = \frac{ESS}{p - 1}$ |
| **Residual**<br>($RSS$) | $\mathbf{y} - \hat{\mathbf{y}}$ | $\sum_{i=1}^n (y_i - \hat{y}_i)^2$ | $n - p$ | $MS_{\text{res}} = \frac{RSS}{n - p} = \hat{\sigma}^2$ |

* **Total Degrees of Freedom ($n - 1$)**: The observation vector $\mathbf{y}$ lives in $\mathbb{R}^n$. Subtracting the sample mean imposes $1$ linear constraint ($\sum_{i=1}^n (y_i - \bar{y}) = 0$), leaving $n - 1$ independent directions of variation.
* **Explained Degrees of Freedom ($p - 1$)**: The model subspace $\operatorname{col}(\mathbf{X})$ has dimension $p$. Because the constant intercept baseline already occupies $1$ dimension ($\operatorname{span}(\mathbf{1})$), the remaining $p - 1$ slope features add $p - 1$ independent degrees of freedom ($1$ dof for simple linear regression).
* **Residual Degrees of Freedom ($n - p$)**: The OLS normal equations force the residuals to be strictly orthogonal to all $p$ columns of $\mathbf{X}$ ($\mathbf{X}^T\mathbf{e} = \mathbf{0}$). These $p$ linear constraints confine the residual vector to the orthogonal complement subspace $\operatorname{col}(\mathbf{X})^\perp$ of dimension $n - p$.

---

#### Fraction of Explained Variation ($R^2$)

The **Coefficient of Determination ($R^2$)** measures the proportion of total variation in $y$ successfully explained by the linear model:

$$
R^2 = \frac{ESS}{TSS} = 1 - \frac{RSS}{TSS} = 1 - \frac{\sum_{i=1}^n (y_i - \hat{y}_i)^2}{\sum_{i=1}^n (y_i - \bar{y})^2}
$$

$R^2$ also relates to the angle $\phi$ of triangle $\triangle(\bar{y}\mathbf{1}, \hat{\mathbf{y}}, \mathbf{y})$ at vertex $\bar{y}\mathbf{1}$:
$$
\cos(\phi) = \frac{\|\hat{\mathbf{y}} - \bar{y}\mathbf{1}\|}{\|\mathbf{y} - \bar{y}\mathbf{1}\|} = \sqrt{\frac{ESS}{TSS}} \implies \cos^2(\phi) = R^2
$$

* If the model explains all variability ($RSS = 0$): 
  $$ESS = TSS \implies R^2 = 1 \to \phi = 0^\circ$$

* If the model performs no better than the constant mean ($ESS = 0$): 
  $$RSS = TSS \implies R^2 = 0 \to \phi = 90^\circ$$

---

#### Relative Improvement by the Model ($F$-statistic)

To assess the relative improvement achieved by the model ($ESS = TSS - RSS$), we
compare the explained sum of squares ($ESS$) to the unexplained residual noise variance ($RSS$).

Since both quantities have different degrees of freedom we divide each term by its respective **degrees of freedom** to compare **Mean Squares**. This ratio is called the $F$-statistics:

$$
F = \frac{MS_{\text{exp}}}{MS_{\text{res}}} = \frac{ESS / (p - 1)}{RSS / (n - p)}
$$

A large $F$-statistic ($F > 1$) indicates large improvements over the baseline model.

## Prediction Uncertainties

Uncertainties in model parameters directly propagate into uncertainties in model predictions.


### Confidence Intervals

For a new input query, we define the column vector $\mathbf{x}_0 = (1, x_{\text{new}})^T$ containing the constant $1$ for the intercept and the predictor value $x_{\text{new}}$.

The leverage (or variance multiplier) for $\mathbf{x}_0$ is given by:

$$
h(\mathbf{x}_0) = \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0 = \frac{1}{n} + \frac{(x_{\text{new}} - \bar{x})^2}{\sum_{i=1}^n (x_i - \bar{x})^2}
$$

::: {.callout-note}
#### Connection to the Full Hat Matrix $\mathbf{H}$
The leverage scalar $h(\mathbf{x}_0)$ quantifies how far any input $\mathbf{x}_0$ lies from the center of the training data. For an in-sample observation $\mathbf{x}_i$, $h(\mathbf{x}_i) = H_{ii}$ is precisely the $i$-th diagonal element of the full $n \times n$ **Hat Matrix**:
$$\mathbf{H} = \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \qquad ( \hat{\mathbf{y}} = \mathbf{H}\mathbf{y})$$
Diagonal elements $H_{ii} \in [1/n, 1]$ measure how strongly observation $y_i$ influences its own fitted prediction $\hat{y}_i$.
:::

Confidence interval for the expected response $\mathbb{E}[y \mid \mathbf{x}_0]$:

$$
\hat{y}(\mathbf{x}_0) \pm t_{n-p, 1-\alpha/2} \cdot \hat{\sigma} \sqrt{h(\mathbf{x}_0)}
$$


```{python}
#| label: confidence_interval
#| code-fold: true
#| code-summary: Python Implementation

# Make predictions on training data with confidence interval
X_pred = x
y_pred = model.predict(X_pred)

n = len(y) # observations
p = X_pred.shape[1] + 1 # parameters (2)

# Calculate residuals and standard error
eps = y - y_pred
sig = np.sqrt(np.sum(eps**2) / (n - p))

# Calculate confidence interval (82% level)
confidence_level = 0.82
t_val = stats.t.ppf((1 + confidence_level) / 2, n - p)
h = 1/n + (X_pred - X_pred.mean())**2 / np.sum((X_pred - X_pred.mean())**2)
se = sig * np.sqrt(h)

lwr = y_pred - t_val * se
upr = y_pred + t_val * se

# Display first few predictions
pred_df = pd.DataFrame({
    'insulin': X_pred.flatten()[:5],
    'fit': y_pred.flatten()[:5],
    'lwr': lwr.flatten()[:5],
    'upr': upr.flatten()[:5]
})
```

```{python}
#| code-fold: true

plt.figure(figsize=FIGSIZE)

plt.scatter(X_pred, y, alpha=0.4, color='#1f77b4', label="Data") 

# Sort for plotting lines
sort_idx = np.argsort(X_pred.flatten())
plt.plot(X_pred[sort_idx], y_pred[sort_idx], 'r-', linewidth=2, label='Fit')

plt.xlabel('Serum Insulin [µU/ml]')
plt.ylabel('Blood Glucose [mg/dL]')

plt.grid(True, alpha=0.3)
```

### Prediction Intervals

The variation of individual patient observations is clearly larger than suggested by the confidence interval shown above.

It is important to remember that in our linear model there are two distinct components of variation:

$$
\|\mathbf{y} - \bar{y}\mathbf{1}\|^2 = \|\mathbf{y} - \hat{\mathbf{y}}\|^2 + \|\hat{\mathbf{y}} - \bar{y}\mathbf{1}\|^2
$$

- **Variance explained by the linear model**: $\|\hat{\mathbf{y}} - \bar{y}\mathbf{1}\|^2$ where $\hat{\mathbf{y}} = \mathbf{X} \hat{\boldsymbol{\theta}}$. Errors in parameter estimation induce uncertainty in the estimated mean $\hat{y}_0$.
- **Unexplained observation noise**: $\|\mathbf{y} - \hat{\mathbf{y}}\|^2 = \|\boldsymbol{\epsilon}\|^2$, where each individual patient exhibits natural physiological deviation $\epsilon \sim \mathcal{N}(0, \sigma^2)$.

To capture where a *new individual patient's measurement* will fall, we must include both parameter uncertainty and individual measurement noise:

$$
h(\mathbf{x}_0) = \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0
$$

$$
\hat{y}(\mathbf{x}_0) \pm t_{n-p, 1-\alpha/2} \cdot \hat{\sigma} \sqrt{1 + h(\mathbf{x}_0)}
$$

```{python}
#| label: prediction_interval
#| code-fold: true
#| code-summary: Python Implementation

# Prediction intervals with full variability
prediction_level = 0.82
t_val_pi = stats.t.ppf((1 + prediction_level) / 2, n - p)

# Prediction interval includes both model uncertainty (h) and residual variance (1)
se_pi = sig * np.sqrt(1 + h)

lwr_pi = y_pred - t_val_pi * se_pi
upr_pi = y_pred + t_val_pi * se_pi

plt.figure(figsize=FIGSIZE)
plt.scatter(X_pred, y, alpha=0.4, color='#1f77b4', label="Data") 

# Sort for plotting lines
sort_idx = np.argsort(X_pred.flatten())
xp = X_pred[sort_idx].flatten()
yp = y_pred[sort_idx].flatten()
yl = lwr_pi[sort_idx].flatten()
yu = upr_pi[sort_idx].flatten()

plt.plot(xp, yp, 'r-', linewidth=2, label='Fit')
plt.fill_between(xp, yl, yu, alpha=0.2, color='red', label=f'{int(prediction_level*100)}% PI')
plt.xlabel('Serum Insulin [µU/ml]')
plt.ylabel('Blood Glucose [mg/dL]')
plt.legend()
plt.title(f'Predictions with Prediction Interval {prediction_level:.2f}')
plt.grid(True, alpha=0.3)
plt.show()
```


::: {.callout-note}
#### Notice 
The **prediction interval** covers the broader scatter of future individual observations. Even with infinite data ($n \to \infty, h \to 0$), the prediction interval *never* collapses to zero because irreducible physiological noise $\sigma$ remains.
:::

### Ignorant Models



```{python}
#| label: models_are_ignorant
#| code-fold: true
#| code-summary: "Extrapolation"

# Generate an unphysical range of insulin values
X_extrap = np.linspace(-800, 800, 400).reshape(-1, 1)
y_extrap = model.predict(X_extrap)

# Leverage and prediction intervals across the extrapolated range
h_extrap = 1/n + (X_extrap - x.mean())**2 / np.sum((x - x.mean())**2)
se_extrap = sig * np.sqrt(1 + h_extrap)

lwr_extrap = y_extrap - t_val_pi * se_extrap
upr_extrap = y_extrap + t_val_pi * se_extrap

plt.figure(figsize=FIGSIZE)

# Plot training data
plt.scatter(x, y, alpha=0.4, color='#1f77b4', label="Observed Data")

# Plot extrapolated fit and prediction intervals
plt.plot(X_extrap, y_extrap, 'r-', linewidth=2, label="Model Fit")
plt.fill_between(
    X_extrap.flatten(),
    lwr_extrap.flatten(),
    upr_extrap.flatten(),
    alpha=0.2,
    color='red',
    label=f"{int(prediction_level*100)}% PI"
)

# Reference lines for physical domain boundaries
plt.axvline(0, color='gray', linestyle='--', alpha=0.7, label="Zero Insulin")
plt.axhline(0, color='black', linestyle=':', alpha=0.5, label="Zero Glucose")

plt.xlabel('Serum Insulin [µU/ml]')
plt.ylabel('Blood Glucose [mg/dL]')
plt.legend(loc='upper left')
plt.title("Models are ignorant.")
plt.grid(True, alpha=0.3)
plt.show()
```


Linear models are agnostic to domain realities: they merely summarize (compress) the observed data within the training range and should not be used far outside the domain in which they were fitted. The model is completely ignorant of what negative serum insulin (or negative glucose level) means.


### Preparing for Multivariate Analysis

In general, models have multi-variate predictors $\mathbf{X}$. In such cases it is impossible to plot target $y$ against all inputs simultaneously. Instead, it is standard practice to plot observed target $y$ against the **predicted** values $\hat{y}$:


## Summary

* **Residual Variance (estimate)**: $\hat{\sigma}^2 = \frac{1}{n-p} \mathbf{e}^T \mathbf{e}$ 
* **Parameter Covariance**: $\operatorname{Cov}(\hat{\boldsymbol{\theta}}) = \hat{\sigma}^2 (\mathbf{X}^T\mathbf{X})^{-1}$
* **Confidence Interval**: $\hat{y}(\mathbf{x}_0) \pm c \cdot \hat{\sigma} \sqrt{h(\mathbf{x}_0)}$
* **Prediction Interval**: $\hat{y}(\mathbf{x}_0) \pm c \cdot \hat{\sigma} \sqrt{1 + h(\mathbf{x}_0)}$
