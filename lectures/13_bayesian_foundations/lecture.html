0. Pre-Class Preparation

Before attending this lecture, please complete the following preparation tasks:

1. The Bayesian Shift: Latent Random Variables

In our previous studies of linear regression, logistic regression, and neural networks, machine learning operated under a frequentist, discriminative framework:

\[ (X, y) \xrightarrow{\text{optimization}} \hat{\boldsymbol{\theta}} \in \mathbb{R}^{p+1}, \qquad x_{\text{new}} \xrightarrow{\hat{\boldsymbol{\theta}}} \widehat{P}(Y = 1 \mid x) = \sigma(x^\top \hat{\boldsymbol{\theta}}) \]

Parameters \(\boldsymbol{\theta}\) were treated as fixed, deterministic constants, and models learned decision boundaries directly by conditioning on observed features \(X\).

NoteThe Core Question

What if, rather than learning a boundary between classes, we first learned what an observation from each class typically looks like?

In the Bayesian framework, we make a fundamental philosophical transition: unobserved entities are treated as random variables described by probability distributions.

Modeling Dimension Discriminative Approach (Logistic Regression) Generative Approach (Naive Bayes / Bayesian)
Object Modeled Conditional probability: \(P(Y \mid X)\) Joint probability: \(P(X, Y) = P(X \mid Y)P(Y)\)
Philosophical Goal Find the separating boundary between classes Model the data-generating mechanism of each class
Input Features \(X\) Treated as given constants without distributions Modeled probabilistically via class densities \(P(X \mid Y)\)
Prediction Engine Direct evaluation: \(\sigma(x^\top \boldsymbol{\theta})\) Probability inversion via Bayes’ Theorem
Sampling Ability Cannot generate synthetic patient observations Can sample realistic new observations \((X, Y)\)

2. Bayes’ Theorem as a Belief Updating Engine

To predict an unobserved class \(Y \in \{0, 1\}\) from observed patient measurements \(x\), Bayes’ theorem provides the formal probability inversion:

\[ P(Y = c \mid X = x) = \frac{P(X = x \mid Y = c) \, P(Y = c)}{P(X = x)} = \frac{P(X = x \mid Y = c) \, P(Y = c)}{\sum_{c'} P(X = x \mid Y = c') \, P(Y = c')} \]

The four components of Bayesian inference are:

  1. Prior Probability \(P(Y = c)\): Prevalence of class \(c\) in the population before observing patient biomarkers.
  2. Likelihood \(P(X = x \mid Y = c)\): Probability (or probability density) of observing measurements \(x\) given the patient belongs to class \(c\).
  3. Posterior Probability \(P(Y = c \mid X = x)\): Updated degree of belief that the patient belongs to class \(c\) after incorporating biomarker evidence.
  4. Evidence / Normalizing Constant \(P(X = x)\): Total marginal probability of observing features \(x\), summing across all possible classes.

2.1 The Bayes Optimal Classification Rule

Because the evidence denominator \(P(X = x)\) is identical for all classes, comparing relative posterior plausibility requires only the numerator:

\[ \hat{y}(x) = \arg\max_{c} P(Y = c) \, P(X = x \mid Y = c) \]

ImportantThe Base-Rate Fallacy in Clinical Medicine

Suppose a disease affects \(1\%\) of a population (\(P(Y=1) = 0.01\)). A diagnostic biomarker test has \(95\%\) sensitivity (\(P(X=1 \mid Y=1) = 0.95\)) and \(95\%\) specificity (\(P(X=0 \mid Y=0) = 0.95\)). If a patient tests positive (\(X = 1\)), what is the probability they have the disease?

\[ P(Y=1 \mid X=1) = \frac{0.95 \times 0.01}{(0.95 \times 0.01) + (0.05 \times 0.99)} = \frac{0.0095}{0.0095 + 0.0495} \approx \mathbf{16.1\%} \]

Despite a \(95\%\) accurate test, a positive result implies only a \(16\%\) posterior probability. Neglecting the prior base rate leads to severe clinical misinterpretation.

3. The “Naive” Conditional Independence Assumption

When a patient possesses multiple symptoms or biomarkers \(\mathbf{x} = (x_1, \dots, x_p)\), the joint likelihood by the probability chain rule is:

\[ P(x_1, \dots, x_p \mid Y = c) = P(x_1 \mid Y = c) \prod_{j=2}^p P(x_j \mid x_1, \dots, x_{j-1}, Y = c) \]

Modeling all high-order conditional dependencies requires an astronomical number of observations. Naive Bayes introduces a simplifying assumption: all features are conditionally independent given the class label:

\[ \boxed{P(\mathbf{x} \mid Y = c) = \prod_{j=1}^p P(x_j \mid Y = c)} \]

This yields the Naive Bayes posterior decision rule:

\[ P(Y = c \mid \mathbf{x}) \propto P(Y = c) \prod_{j=1}^p P(x_j \mid Y = c) \]

3.1 The Parameter Explosion Paradox

Why make an assumption that seems biologically or physically unrealistic?

Feature Dimension (\(p\) binary markers) Unrestricted Joint Model Parameters (\(2^p - 1\)) Naive Bayes Parameters (\(p\)) Computational Growth
\(p = 1\) \(2^1 - 1 = 1\) \(1\) Identical baseline
\(p = 2\) \(2^2 - 1 = 3\) \(2\) Joint requires contingency tables
\(p = 5\) \(2^5 - 1 = 31\) \(5\) \(6\times\) parameter reduction
\(p = 10\) \(2^{10} - 1 = 1{,}023\) \(10\) \(100\times\) parameter reduction
\(p = 20\) \(2^{20} - 1 \approx 1{,}048{,}575\) \(20\) Exponential collapse to linear

Without the independence assumption, \(20\) binary features require estimating over 1 million parameters per class. Naive Bayes requires estimating only 20 parameters per class.

Critical Distinction: Conditional independence within a class (\(X_1 \perp X_2 \mid Y\)) does not imply unconditional independence in the pooled population. Two symptoms can be strongly correlated overall simply because both are caused by the underlying disease.

4. Bernoulli Naive Bayes and the Logistic Link

Consider a clinical screening setup with binary symptom indicators \(X_j \in \{0, 1\}\) (e.g., \(X_1\): High Fasting Glucose \(\ge 126\,\text{mg/dL}\); \(X_2\): Systolic Hypertension \(\ge 140\,\text{mmHg}\)):

Parameter Diseased (\(Y = 1\)) Healthy (\(Y = 0\))
Prior Prevalence \(P(Y = c)\) \(0.20\) \(0.80\)
Elevated Glucose \(P(X_1 = 1 \mid Y = c)\) \(0.80\) \(0.20\)
Elevated Blood Pressure \(P(X_2 = 1 \mid Y = c)\) \(0.75\) \(0.25\)

4.1 Step-by-Step Patient Classification

A new patient arrives at the clinic with both risk markers present: \(\mathbf{x}^* = (1, 1)\).

  1. Compute unnormalized joint score for the Diseased class (\(s_1\)): \[s_1 = P(Y=1) \cdot P(X_1=1 \mid Y=1) \cdot P(X_2=1 \mid Y=1) = 0.20 \times 0.80 \times 0.75 = \mathbf{0.12}\]

  2. Compute unnormalized joint score for the Healthy class (\(s_0\)): \[s_0 = P(Y=0) \cdot P(X_1=1 \mid Y=0) \cdot P(X_2=1 \mid Y=0) = 0.80 \times 0.20 \times 0.25 = \mathbf{0.04}\]

  3. Normalize by the total evidence: \[P(Y=1 \mid \mathbf{x}^*) = \frac{s_1}{s_1 + s_0} = \frac{0.12}{0.12 + 0.04} = \frac{0.12}{0.16} = \mathbf{0.75} \quad (75\%)\]

4.2 Parameter Estimation & Laplace Smoothing

From a training set of \(N\) patients, class priors and feature probabilities are estimated by empirical proportions:

\[ \widehat{P}(Y=c) = \frac{N_c}{N}, \qquad \hat{q}_{jc} = \widehat{P}(X_j = 1 \mid Y = c) = \frac{N_{jc}}{N_c} \]

WarningThe Zero-Frequency Trap & Laplace Smoothing

If a symptom never appears in training patients of class \(c\) (\(N_{jc} = 0\)), then \(\hat{q}_{jc} = 0\). In Naive Bayes, this zero multiplies through the entire product, forcing the posterior to zero regardless of all other evidence.

We prevent this by adding pseudo-counts via Laplace / additive smoothing (\(\alpha = 1\)): \[\hat{q}_{jc} = \frac{N_{jc} + \alpha}{N_c + 2\alpha}\]

4.3 The Surprising Equivalence to Logistic Regression

For binary outcomes, examine the posterior log-odds:

\[ \log \frac{P(Y=1 \mid \mathbf{x})}{P(Y=0 \mid \mathbf{x})} = \log \frac{P(Y=1)}{P(Y=0)} + \sum_{j=1}^p \log \frac{P(x_j \mid Y=1)}{P(x_j \mid Y=0)} \]

Because \(P(x_j \mid Y=c) = q_{jc}^{x_j} (1 - q_{jc})^{1 - x_j}\) for binary indicators, algebraic substitution yields:

\[ \boxed{\log \frac{P(Y=1 \mid \mathbf{x})}{P(Y=0 \mid \mathbf{x})} = \beta_0 + \sum_{j=1}^p \beta_j x_j} \]

where the feature weights are the log-odds ratios:

\[ \beta_j = \log \left( \frac{q_{j1} (1 - q_{j0})}{q_{j0} (1 - q_{j1})} \right), \qquad \beta_0 = \log \frac{P(Y=1)}{P(Y=0)} + \sum_{j=1}^p \log \frac{1 - q_{j1}}{1 - q_{j0}} \]

Taking the sigmoid inversion of the log-odds proves that:

\[ P(Y = 1 \mid \mathbf{x}) = \sigma\left(\beta_0 + \sum_{j=1}^p \beta_j x_j\right) \]

ImportantFundamental Insight

Bernoulli Naive Bayes and Logistic Regression possess the exact same linear mathematical functional form. However, they arrive at their coefficients through contrasting paradigms: - Logistic Regression directly maximizes conditional likelihood \(\prod P(y_i \mid x_i)\) via numerical gradient descent. - Naive Bayes factors the joint distribution and computes closed-form counting estimates.

6. Continuous Features and Gaussian Naive Bayes

When biomarkers are continuous (e.g. glucose in \(\text{mg/dL}\) and blood pressure in \(\text{mmHg}\)), Gaussian Naive Bayes models feature likelihoods using one-dimensional normal densities:

\[ X_j \mid (Y = c) \sim \mathcal{N}(\mu_{jc}, \sigma_{jc}^2) \implies P(x_j \mid Y = c) = \frac{1}{\sqrt{2\pi \sigma_{jc}^2}} \exp\left( -\frac{(x_j - \mu_{jc})^2}{2\sigma_{jc}^2} \right) \]

This model restricts the full covariance matrix to a diagonal matrix:

\[ \boldsymbol{\Sigma}_c = \operatorname{diag}(\sigma_{c1}^2, \dots, \sigma_{cp}^2) \]

Geometrically: - If feature variances are equal across classes (\(\sigma_{j1}^2 = \sigma_{j0}^2\)), the quadratic terms \((x_j - \mu)^2\) cancel in the log-odds ratio, creating a linear decision hyperplane (identical to Linear Discriminant Analysis with diagonal covariance). - If variances differ (\(\sigma_{j1}^2 \neq \sigma_{j0}^2\)), quadratic terms remain, yielding curved parabolic or elliptical decision boundaries.

NoteSample Efficiency: Ng & Jordan (2001) Result

Andrew Ng and Michael Jordan proved that Gaussian Naive Bayes approaches its asymptotic classification error rate with only \(\mathcal{O}(\log p)\) training observations, whereas Logistic Regression requires \(\mathcal{O}(p)\) observations. On small sample sizes (\(N \ll p\)), Naive Bayes often outperforms Logistic Regression even when conditional independence is violated.

7.1 From Class Inference to Parameter Inference

In Naive Bayes, we used Bayes’ rule to infer an unobserved discrete class state \(Y \in \{0, 1\}\) from observed data \(X\):

\[ P(Y = c \mid X = x) = \frac{P(X = x \mid Y = c) \, P(Y = c)}{\sum_{c'} P(X = x \mid Y = c') \, P(Y = c')} \]

Notice that the denominator is a straightforward discrete summation over \(K\) classes.

ImportantBridge to Week 14: Maximum A Posteriori (MAP) & Continuous Parameters

What happens if we apply Bayes’ rule not to discrete class labels \(Y\), but to continuous model parameters \(\boldsymbol{\theta} \in \mathbb{R}^p\)?

\[ p(\boldsymbol{\theta} \mid \mathcal{D}) = \frac{p(\mathcal{D} \mid \boldsymbol{\theta}) \, p(\boldsymbol{\theta})}{\int_{\mathbb{R}^p} p(\mathcal{D} \mid \boldsymbol{\theta}) \, p(\boldsymbol{\theta}) \, d\boldsymbol{\theta}} \]

In Lecture 14, we will discover: 1. How putting a Gaussian prior on parameters \(\boldsymbol{\theta} \sim \mathcal{N}(0, \tau^2 \mathbf{I})\) mathematically derives the \(L_2\) Ridge penalty. 2. Why the continuous denominator integral becomes analytically intractable, paving the path toward Markov Chain Monte Carlo (MCMC) and PyMC in Week 15.

## 1. The Bayesian Shift: Latent Random Variables

In our previous studies of linear regression, logistic regression, and neural networks, machine learning operated under a **frequentist, discriminative framework**:

$$
(X, y) \xrightarrow{\text{optimization}} \hat{\boldsymbol{\theta}} \in \mathbb{R}^{p+1},
\qquad
x_{\text{new}} \xrightarrow{\hat{\boldsymbol{\theta}}} \widehat{P}(Y = 1 \mid x) = \sigma(x^\top \hat{\boldsymbol{\theta}})
$$

Parameters $\boldsymbol{\theta}$ were treated as fixed, deterministic constants, and models learned decision boundaries directly by conditioning on observed features $X$.

::: {.callout-note}
### The Core Question
What if, rather than learning a boundary between classes, we first learned what an observation from each class typically looks like?
:::

In the **Bayesian framework**, we make a fundamental philosophical transition: **unobserved entities are treated as random variables** described by probability distributions.

| Modeling Dimension | Discriminative Approach (Logistic Regression) | Generative Approach (Naive Bayes / Bayesian) |
| :--- | :--- | :--- |
| **Object Modeled** | Conditional probability: $P(Y \mid X)$ | Joint probability: $P(X, Y) = P(X \mid Y)P(Y)$ |
| **Philosophical Goal** | Find the separating boundary between classes | Model the data-generating mechanism of each class |
| **Input Features $X$** | Treated as given constants without distributions | Modeled probabilistically via class densities $P(X \mid Y)$ |
| **Prediction Engine** | Direct evaluation: $\sigma(x^\top \boldsymbol{\theta})$ | Probability inversion via **Bayes' Theorem** |
| **Sampling Ability** | Cannot generate synthetic patient observations | Can sample realistic new observations $(X, Y)$ |

## 2. Bayes' Theorem as a Belief Updating Engine

To predict an unobserved class $Y \in \{0, 1\}$ from observed patient measurements $x$, Bayes' theorem provides the formal probability inversion:

$$
P(Y = c \mid X = x) = \frac{P(X = x \mid Y = c) \, P(Y = c)}{P(X = x)} = \frac{P(X = x \mid Y = c) \, P(Y = c)}{\sum_{c'} P(X = x \mid Y = c') \, P(Y = c')}
$$

The four components of Bayesian inference are:

1. **Prior Probability $P(Y = c)$:** Prevalence of class $c$ in the population *before* observing patient biomarkers.
2. **Likelihood $P(X = x \mid Y = c)$:** Probability (or probability density) of observing measurements $x$ *given* the patient belongs to class $c$.
3. **Posterior Probability $P(Y = c \mid X = x)$:** Updated degree of belief that the patient belongs to class $c$ *after* incorporating biomarker evidence.
4. **Evidence / Normalizing Constant $P(X = x)$:** Total marginal probability of observing features $x$, summing across all possible classes.

### 2.1 The Bayes Optimal Classification Rule

Because the evidence denominator $P(X = x)$ is identical for all classes, comparing relative posterior plausibility requires only the numerator:

$$
\hat{y}(x) = \arg\max_{c} P(Y = c) \, P(X = x \mid Y = c)
$$

::: {.callout-important}
### The Base-Rate Fallacy in Clinical Medicine
Suppose a disease affects $1\%$ of a population ($P(Y=1) = 0.01$). A diagnostic biomarker test has $95\%$ sensitivity ($P(X=1 \mid Y=1) = 0.95$) and $95\%$ specificity ($P(X=0 \mid Y=0) = 0.95$). If a patient tests positive ($X = 1$), what is the probability they have the disease?

$$
P(Y=1 \mid X=1) = \frac{0.95 \times 0.01}{(0.95 \times 0.01) + (0.05 \times 0.99)} = \frac{0.0095}{0.0095 + 0.0495} \approx \mathbf{16.1\%}
$$

Despite a $95\%$ accurate test, a positive result implies only a $16\%$ posterior probability. Neglecting the prior base rate leads to severe clinical misinterpretation.
:::

## 3. The "Naive" Conditional Independence Assumption

When a patient possesses multiple symptoms or biomarkers $\mathbf{x} = (x_1, \dots, x_p)$, the joint likelihood by the probability chain rule is:

$$
P(x_1, \dots, x_p \mid Y = c) = P(x_1 \mid Y = c) \prod_{j=2}^p P(x_j \mid x_1, \dots, x_{j-1}, Y = c)
$$

Modeling all high-order conditional dependencies requires an astronomical number of observations. **Naive Bayes** introduces a simplifying assumption: **all features are conditionally independent given the class label**:

$$
\boxed{P(\mathbf{x} \mid Y = c) = \prod_{j=1}^p P(x_j \mid Y = c)}
$$

This yields the Naive Bayes posterior decision rule:

$$
P(Y = c \mid \mathbf{x}) \propto P(Y = c) \prod_{j=1}^p P(x_j \mid Y = c)
$$

### 3.1 The Parameter Explosion Paradox

Why make an assumption that seems biologically or physically unrealistic?

| Feature Dimension ($p$ binary markers) | Unrestricted Joint Model Parameters ($2^p - 1$) | Naive Bayes Parameters ($p$) | Computational Growth |
| :---: | :---: | :---: | :--- |
| **$p = 1$** | $2^1 - 1 = 1$ | $1$ | Identical baseline |
| **$p = 2$** | $2^2 - 1 = 3$ | $2$ | Joint requires contingency tables |
| **$p = 5$** | $2^5 - 1 = 31$ | $5$ | $6\times$ parameter reduction |
| **$p = 10$** | $2^{10} - 1 = 1{,}023$ | $10$ | $100\times$ parameter reduction |
| **$p = 20$** | $2^{20} - 1 \approx 1{,}048{,}575$ | $20$ | Exponential collapse to linear |

Without the independence assumption, $20$ binary features require estimating over **1 million parameters** per class. Naive Bayes requires estimating only **20 parameters** per class.

> **Critical Distinction:** Conditional independence *within a class* ($X_1 \perp X_2 \mid Y$) does **not** imply unconditional independence in the pooled population. Two symptoms can be strongly correlated overall simply because both are caused by the underlying disease.

## 4. Bernoulli Naive Bayes and the Logistic Link

Consider a clinical screening setup with binary symptom indicators $X_j \in \{0, 1\}$ (e.g., $X_1$: High Fasting Glucose $\ge 126\,\text{mg/dL}$; $X_2$: Systolic Hypertension $\ge 140\,\text{mmHg}$):

| Parameter | Diseased ($Y = 1$) | Healthy ($Y = 0$) |
| :--- | :---: | :---: |
| **Prior Prevalence $P(Y = c)$** | $0.20$ | $0.80$ |
| **Elevated Glucose $P(X_1 = 1 \mid Y = c)$** | $0.80$ | $0.20$ |
| **Elevated Blood Pressure $P(X_2 = 1 \mid Y = c)$** | $0.75$ | $0.25$ |

### 4.1 Step-by-Step Patient Classification

A new patient arrives at the clinic with both risk markers present: $\mathbf{x}^* = (1, 1)$.

1. Compute unnormalized joint score for the Diseased class ($s_1$):
   $$s_1 = P(Y=1) \cdot P(X_1=1 \mid Y=1) \cdot P(X_2=1 \mid Y=1) = 0.20 \times 0.80 \times 0.75 = \mathbf{0.12}$$

2. Compute unnormalized joint score for the Healthy class ($s_0$):
   $$s_0 = P(Y=0) \cdot P(X_1=1 \mid Y=0) \cdot P(X_2=1 \mid Y=0) = 0.80 \times 0.20 \times 0.25 = \mathbf{0.04}$$

3. Normalize by the total evidence:
   $$P(Y=1 \mid \mathbf{x}^*) = \frac{s_1}{s_1 + s_0} = \frac{0.12}{0.12 + 0.04} = \frac{0.12}{0.16} = \mathbf{0.75} \quad (75\%)$$

### 4.2 Parameter Estimation & Laplace Smoothing

From a training set of $N$ patients, class priors and feature probabilities are estimated by empirical proportions:

$$
\widehat{P}(Y=c) = \frac{N_c}{N}, \qquad \hat{q}_{jc} = \widehat{P}(X_j = 1 \mid Y = c) = \frac{N_{jc}}{N_c}
$$

::: {.callout-warning}
### The Zero-Frequency Trap & Laplace Smoothing
If a symptom never appears in training patients of class $c$ ($N_{jc} = 0$), then $\hat{q}_{jc} = 0$. In Naive Bayes, this zero multiplies through the entire product, forcing the posterior to zero regardless of all other evidence.

We prevent this by adding pseudo-counts via **Laplace / additive smoothing** ($\alpha = 1$):
$$\hat{q}_{jc} = \frac{N_{jc} + \alpha}{N_c + 2\alpha}$$
:::

### 4.3 The Surprising Equivalence to Logistic Regression

For binary outcomes, examine the **posterior log-odds**:

$$
\log \frac{P(Y=1 \mid \mathbf{x})}{P(Y=0 \mid \mathbf{x})} = \log \frac{P(Y=1)}{P(Y=0)} + \sum_{j=1}^p \log \frac{P(x_j \mid Y=1)}{P(x_j \mid Y=0)}
$$

Because $P(x_j \mid Y=c) = q_{jc}^{x_j} (1 - q_{jc})^{1 - x_j}$ for binary indicators, algebraic substitution yields:

$$
\boxed{\log \frac{P(Y=1 \mid \mathbf{x})}{P(Y=0 \mid \mathbf{x})} = \beta_0 + \sum_{j=1}^p \beta_j x_j}
$$

where the feature weights are the log-odds ratios:

$$
\beta_j = \log \left( \frac{q_{j1} (1 - q_{j0})}{q_{j0} (1 - q_{j1})} \right),
\qquad
\beta_0 = \log \frac{P(Y=1)}{P(Y=0)} + \sum_{j=1}^p \log \frac{1 - q_{j1}}{1 - q_{j0}}
$$

Taking the sigmoid inversion of the log-odds proves that:

$$
P(Y = 1 \mid \mathbf{x}) = \sigma\left(\beta_0 + \sum_{j=1}^p \beta_j x_j\right)
$$

::: {.callout-important}
### Fundamental Insight
Bernoulli Naive Bayes and Logistic Regression possess the **exact same linear mathematical functional form**. However, they arrive at their coefficients through contrasting paradigms:
- **Logistic Regression** directly maximizes conditional likelihood $\prod P(y_i \mid x_i)$ via numerical gradient descent.
- **Naive Bayes** factors the joint distribution and computes closed-form counting estimates.
:::

## 6. Continuous Features and Gaussian Naive Bayes

When biomarkers are continuous (e.g. glucose in $\text{mg/dL}$ and blood pressure in $\text{mmHg}$), **Gaussian Naive Bayes** models feature likelihoods using one-dimensional normal densities:

$$
X_j \mid (Y = c) \sim \mathcal{N}(\mu_{jc}, \sigma_{jc}^2)
\implies
P(x_j \mid Y = c) = \frac{1}{\sqrt{2\pi \sigma_{jc}^2}} \exp\left( -\frac{(x_j - \mu_{jc})^2}{2\sigma_{jc}^2} \right)
$$

This model restricts the full covariance matrix to a **diagonal matrix**:

$$
\boldsymbol{\Sigma}_c = \operatorname{diag}(\sigma_{c1}^2, \dots, \sigma_{cp}^2)
$$

Geometrically:
- If feature variances are equal across classes ($\sigma_{j1}^2 = \sigma_{j0}^2$), the quadratic terms $(x_j - \mu)^2$ cancel in the log-odds ratio, creating a **linear decision hyperplane** (identical to Linear Discriminant Analysis with diagonal covariance).
- If variances differ ($\sigma_{j1}^2 \neq \sigma_{j0}^2$), quadratic terms remain, yielding **curved parabolic or elliptical decision boundaries**.

::: {.callout-note}
### Sample Efficiency: Ng & Jordan (2001) Result
Andrew Ng and Michael Jordan proved that Gaussian Naive Bayes approaches its asymptotic classification error rate with only $\mathcal{O}(\log p)$ training observations, whereas Logistic Regression requires $\mathcal{O}(p)$ observations. On small sample sizes ($N \ll p$), Naive Bayes often outperforms Logistic Regression even when conditional independence is violated.
:::

## 7. Review, Synthesis & The Bridge to Parameter Inference

| Aspect | Logistic Regression | Naive Bayes | Full Bayesian Inference |
| :--- | :--- | :--- | :--- |
| **Model Type** | Discriminative | Generative Classifier | Fully Probabilistic |
| **Parameters $\boldsymbol{\theta}$** | Fixed weights $\hat{\boldsymbol{\theta}}$ | Class counts / Gaussian $(\mu, \sigma^2)$ | **Random variables** $p(\boldsymbol{\theta} \mid \mathcal{D})$ |
| **Prediction Function** | $\sigma(x^\top \hat{\boldsymbol{\theta}})$ | $\arg\max_c P(Y=c)\prod P(x_j \mid c)$ | Posterior predictive distribution |
| **Independence Assumption** | None on features $X$ | Strict: $X_j \perp X_k \mid Y$ | Explicitly defined in graphical model |
| **Sample Efficiency** | Requires $\mathcal{O}(p)$ samples | Converges in $\mathcal{O}(\log p)$ samples | Optimal with informative priors |
| **Calibration** | Well-calibrated probabilities | Overconfident / extreme probabilities | Full predictive uncertainty credible intervals |

### 7.1 From Class Inference to Parameter Inference

In Naive Bayes, we used Bayes' rule to infer an unobserved *discrete class state* $Y \in \{0, 1\}$ from observed data $X$:

$$
P(Y = c \mid X = x) = \frac{P(X = x \mid Y = c) \, P(Y = c)}{\sum_{c'} P(X = x \mid Y = c') \, P(Y = c')}
$$

Notice that the denominator is a straightforward discrete summation over $K$ classes.

::: {.callout-important}
### Bridge to Week 14: Maximum A Posteriori (MAP) & Continuous Parameters
What happens if we apply Bayes' rule not to discrete class labels $Y$, but to **continuous model parameters $\boldsymbol{\theta} \in \mathbb{R}^p$**?

$$
p(\boldsymbol{\theta} \mid \mathcal{D}) = \frac{p(\mathcal{D} \mid \boldsymbol{\theta}) \, p(\boldsymbol{\theta})}{\int_{\mathbb{R}^p} p(\mathcal{D} \mid \boldsymbol{\theta}) \, p(\boldsymbol{\theta}) \, d\boldsymbol{\theta}}
$$

In **Lecture 14**, we will discover:
1. How putting a Gaussian prior on parameters $\boldsymbol{\theta} \sim \mathcal{N}(0, \tau^2 \mathbf{I})$ mathematically derives the **$L_2$ Ridge penalty**.
2. Why the continuous denominator integral becomes **analytically intractable**, paving the path toward **Markov Chain Monte Carlo (MCMC)** and **PyMC** in Week 15.
:::
