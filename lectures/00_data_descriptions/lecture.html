# Helper function to render DataFrame head as a clean Markdown table
def df_to_markdown(dataframe):
    cols = list(dataframe.columns)
    header = "| " + " | ".join(cols) + " |\n| " + " | ".join([":---:"] * len(cols)) + " |\n"
    rows = "\n".join("| " + " | ".join(f"{val:.4f}" if isinstance(val, float) else str(val) for val in row) + " |" for row in dataframe.values)
    return header + rows

1. Celestial Mechanics: Data from NASA

To explore how data measurements behave in physical systems, we analyze real long-term observational ephemeris data of the planet Mars tracked over a 125-year timeline (1900–2025) obtained from the NASA JPL Horizons API.

Astronomers track planetary motions using three primary observables:

  • Right Ascension (RA): Celestial longitude measured in hours (\(0\) to \(24\text{ h}\)).
  • Declination (Dec): Celestial latitude measured in degrees (\(-26.5^\circ\) to \(+26.5^\circ\)).
  • Apparent Magnitude (Magnitude): Observed luminosity on an inverse logarithmic brightness scale.
Read Data 
# Query NASA JPL Horizons API for Mars (Body 499) observed from Earth (500@399) over 125 years (1900-2025)
url = ("https://ssd.jpl.nasa.gov/api/horizons.api?"
       "format=json&COMMAND='499'&CENTER='500@399'&MAKE_EPHEM='YES'"
       "&EPHEM_TYPE='OBSERVER'&START_TIME='1900-01-01'&STOP_TIME='2025-01-01'"
       "&STEP_SIZE='14d'&QUANTITIES='1,9'")

req = urllib.request.urlopen(url)
data = json.loads(req.read().decode('utf-8'))
result_text = data['result']
Process Data 
# Parse ephemeris records between $$SOE (Start of Ephemeris) and $$EOE (End of Ephemeris)
start_idx = result_text.find('$$SOE') + 6
end_idx = result_text.find('$$EOE')
lines = result_text[start_idx:end_idx].strip().split('\n')

records = []
for line in lines:
    parts = line.strip().split()
    if len(parts) >= 9:
        # Convert sexagesimal RA (hours, minutes, seconds) to decimal hours [0, 24)
        ra_h = float(parts[2]) + float(parts[3])/60.0 + float(parts[4])/3600.0
        
        # Convert sexagesimal Dec (degrees, arcminutes, arcseconds) to signed decimal degrees [-90, +90]
        dec_deg_val = float(parts[5])
        sign = -1.0 if parts[5].startswith('-') else 1.0
        dec_deg = dec_deg_val + sign * (float(parts[6])/60.0 + float(parts[7])/3600.0)

2. Planetary Models and Simulation

In addition to real empirical data, we can build a mathematical model of planetary orbits. Simplified models (such as assuming a circular orbit with constant velocity) capture fundamental behaviors (parallactic retrograde loops, declination bounds, and opposition brightness flares), but miss subtle physical effects like Keplerian speed variations near aphelion.

The code block below generates a 2,000-year synthetic dataset stored in DataFrame df_sim:

Simulate Data 
# 1. Parameter setup (2,000 years * 52.1775 weeks = 104,355 data points)
np.random.seed(1337)
jahre = 2000
wochen_pro_jahr = 52.1775
n_points = int(jahre * wochen_pro_jahr)

# Time axis (in years)
t = np.linspace(0, jahre, n_points)

# --- Variable 1: Right Ascension (RA) ---
# Simplified circular orbit assumption (constant orbital speed)
ra = np.mod(t * (1.0 / 1.8808) * 24, 24)
ra = np.mod(ra + np.sin(2 * np.pi * t) * 0.8, 24)

# --- Variable 2: Declination (Dec) ---
dec = 26.5 * np.sin(2 * np.pi * t + np.sin(2 * np.pi * t / 1.8808) * 0.1)

# --- Variable 3: Apparent Magnitude ---
synodisch = np.mod(t, 2.135)
distanz_effekt = np.exp(-((synodisch - 1.07) / 0.12)**2)
exzentrizitaet = 1.0 + 0.3 * np.sin(2 * np.pi * t / 15.0)

magnitude = 1.75 - (3.85 * distanz_effekt * exzentrizitaet)
magnitude = np.clip(magnitude, -2.94, 1.86)

# Construct synthetic DataFrame `df_sim`
df_sim = pd.DataFrame({
    'RA': ra,
    'Dec': dec,
    'Magnitude': magnitude
})

print(f"Synthetic simulation complete: {len(df_sim):,} data points generated in DataFrame `df_sim`.")

4. Interpretations

4.1 Right Ascension (RA)

  • RA spans \([0, 24)\) hours across the celestial sphere.
  • In real observational data (df), RA exhibits a pronounced accumulation peak around \(\sim 11.5\text{ h}\).
  • The position of this peak corresponds to Aphelion (where Mars moves slowest in its orbit according to Kepler’s Second Law, spending more time per degree).
NoteDetailed Analysis of Right Ascension & Real Physics vs. Circular Models
  • Real Physics (Keplerian Aphelion Slowdown): Real Mars has an eccentric orbit (\(e \approx 0.0934\)). Its Aphelion (farthest point from the Sun) is located at ecliptic longitude \(\sim 154^\circ\), corresponding to \(\text{RA} \approx 11\text{ h} - 12\text{ h}\) (constellation Leo/Virgo). According to Kepler’s Second Law (Equal Areas in Equal Times), Mars travels slowest near Aphelion (\(v \approx 21.9\text{ km/s}\)) and fastest near Perihelion (\(v \approx 26.5\text{ km/s}\)). Mars spends \(\sim 20\%\) more time per orbit lingering near Aphelion, creating a real physical accumulation peak around \(\text{RA} \sim 11.5\text{ h}\) in df.
  • Circular Model Assumption: A simplified circular generator uses constant velocity \(\text{ra} = \frac{24}{1.8808} t + \text{parallax}\). Because speed is held constant, the underlying distribution of a circular model is perfectly uniform across \([0, 24)\text{ h}\).
  • Circular Topology: RA represents directional angles on the celestial sphere (\(0.0\text{ h}\) and \(23.99\text{ h}\) are physically adjacent). Standard linear summary statistics treat them as opposite extremes, rendering linear means (\(\approx 11.65\text{ h}\)) misleading without directional/circular statistics.

4.2 Declination (Dec)

  • Dec exhibits a strongly bimodal (U-shaped) distribution, with twin peaks concentrated near the extrema of \(\pm 26.5^\circ\).
  • The mean (\(\approx +1.20^\circ\)) and median (\(\approx +2.37^\circ\)) point directly to the location of minimum observed data density.
  • Origin of the \(\pm 26.5^\circ\) Extrema: The declination boundaries are determined by Earth’s axial tilt (\(23.44^\circ\)) plus Mars’ orbital inclination (\(1.85^\circ\)) relative to the ecliptic plane, causing Mars’ celestial latitude to oscillate smoothly between \(-26.5^\circ\) and \(+26.5^\circ\).
NoteDetailed Analysis of Declination
  • Harmonic Dwell Time: Because harmonic motion slows down near maximum amplitudes (\(\frac{d}{dt}\sin(\omega t) \to 0\)), Mars lingers near its northern and southern turning points (\(\pm 26.5^\circ\)) and rushes through the celestial equator (\(0^\circ\)).
  • Failure of Unimodal Metrics: Summary statistics like mean and variance assume a single central cluster. Reporting \(\mu = 1.20^\circ\) and \(\sigma = 17.26^\circ\) makes the dataset sound like a bell curve centered at \(0^\circ\), completely masking the twin peaks at the boundaries.

4.3 Apparent Magnitude (Magnitude)

  • Highly asymmetric distribution with a dominant baseline peak near faint magnitudes (\(+1.1\text{ to }+1.8\) mag) and a long left tail extending to bright magnitudes (down to \(-2.95\) mag during opposition flares).
  • The mean (\(0.70\) mag) is distorted by rare opposition flares and is not very meaningful (giving a magnitude at which Mars is almost never observed). Baseline visual faintness dominates the quantiles (where larger numerical magnitude values denote dimmer visual brightness).
NoteDetailed Analysis of Apparent Magnitude
  • Distortion by Rare Events: For ~90% of its synodic cycle, Mars is far from Earth and faint. During brief opposition alignments, brightness flares up. The mean (\(0.70\) mag) is pulled away from the true baseline mode by these rare flares, giving an average value at which Mars is almost never observed.
  • Quantile Collapse: Because baseline faintness dominates, interquartile range (\(IQR\)) collapses, hiding the extreme flare range down to \(-2.95\) mag during perihelic oppositions.

5. Takeaways and Skepticism

  1. Beware the Gaussian Default: Introductory courses heavily rely on Normal distribution assumptions (\(\mu, \sigma^2\)). As planetary movements demonstrate, physical processes frequently produce uniform, bimodal, and long-tailed distributions where standard means and variances fail to describe the data.
  2. Summary Tables Condense, But Also Conceal: Aggregating data points into 8 numbers per variable collapses critical spatial and modal structures (such as bimodal peaks in Dec or opposition spikes in Magnitude).
  3. Always Look at the Data (EDA First): Visual inspection (histograms and KDE density plots) must precede numerical summary calculations. Visual plots immediately reveal multi-modality, skewness, boundary effects, and circular topologies.
  4. Context & Domain Expertise Matter: Observables are physical measurements over time. Understanding planetary orbits (Kepler’s laws, retrogrades, synodic cycles, aphelion slowing) explains why distributions take their specific shapes. Note also domain conventions: in astronomy, magnitude is an inverted logarithmic scale where larger numbers represent dimmer objects, and lower/negative numbers represent brighter objects.
  5. Beware of Data Scales, Units, and Transformations:
    • Variables within the same dataset often use completely different units and scales: RA in hours (\(0–24\text{ h}\)), Dec in degrees (\(-90^\circ\) to \(+90^\circ\)), and Magnitude on an inverted logarithmic scale.
    • Transforming, standardizing, or normalizing data (e.g. z-score standardization or min-max scaling) requires careful attention to domain units and physical topologies before applying standard algorithms blindly.
  6. Beware of Visualization Artifacts:
    • Analysts must carefully distinguish between model assumptions, physical mechanisms, and smoothing artifacts.
    • Density estimation algorithms can introduce boundary smoothing effects (such as KDE edge leaks), whereas physical drivers (like Keplerian velocity variations near aphelion) produce genuine non-uniform data structures. Visual inspection must always be paired with physical domain understanding.

# 4. Interpretations

### 4.1 Right Ascension (`RA`)

- `RA` spans $[0, 24)$ hours across the celestial sphere.
- In real observational data (`df`), `RA` exhibits a pronounced accumulation peak around $\sim 11.5\text{ h}$.
- The position of this peak corresponds to **Aphelion** (where Mars moves slowest in its orbit according to Kepler's Second Law, spending more time per degree).

::: {.callout-note collapse="true"}
### Detailed Analysis of Right Ascension & Real Physics vs. Circular Models
- **Real Physics (Keplerian Aphelion Slowdown)**: Real Mars has an eccentric orbit ($e \approx 0.0934$). Its **Aphelion** (farthest point from the Sun) is located at ecliptic longitude $\sim 154^\circ$, corresponding to **$\text{RA} \approx 11\text{ h} - 12\text{ h}$** (constellation Leo/Virgo). According to Kepler's Second Law (*Equal Areas in Equal Times*), Mars travels **slowest near Aphelion** ($v \approx 21.9\text{ km/s}$) and **fastest near Perihelion** ($v \approx 26.5\text{ km/s}$). Mars spends $\sim 20\%$ more time per orbit lingering near Aphelion, creating a real physical accumulation peak around $\text{RA} \sim 11.5\text{ h}$ in `df`.
- **Circular Model Assumption**: A simplified circular generator uses constant velocity $\text{ra} = \frac{24}{1.8808} t + \text{parallax}$. Because speed is held constant, the underlying distribution of a circular model is perfectly uniform across $[0, 24)\text{ h}$.
- **Circular Topology**: RA represents directional angles on the celestial sphere ($0.0\text{ h}$ and $23.99\text{ h}$ are physically adjacent). Standard linear summary statistics treat them as opposite extremes, rendering linear means ($\approx 11.65\text{ h}$) misleading without directional/circular statistics.
:::

### 4.2 Declination (`Dec`)

- `Dec` exhibits a strongly **bimodal (U-shaped)** distribution, with twin peaks concentrated near the extrema of $\pm 26.5^\circ$.
- The mean ($\approx +1.20^\circ$) and median ($\approx +2.37^\circ$) point directly to the location of **minimum observed data density**.
- **Origin of the $\pm 26.5^\circ$ Extrema**: The declination boundaries are determined by Earth's axial tilt ($23.44^\circ$) plus Mars' orbital inclination ($1.85^\circ$) relative to the ecliptic plane, causing Mars' celestial latitude to oscillate smoothly between $-26.5^\circ$ and $+26.5^\circ$.

::: {.callout-note collapse="true"}
### Detailed Analysis of Declination
- **Harmonic Dwell Time**: Because harmonic motion slows down near maximum amplitudes ($\frac{d}{dt}\sin(\omega t) \to 0$), Mars lingers near its northern and southern turning points ($\pm 26.5^\circ$) and rushes through the celestial equator ($0^\circ$).
- **Failure of Unimodal Metrics**: Summary statistics like mean and variance assume a single central cluster. Reporting $\mu = 1.20^\circ$ and $\sigma = 17.26^\circ$ makes the dataset sound like a bell curve centered at $0^\circ$, completely masking the twin peaks at the boundaries.
:::

### 4.3 Apparent Magnitude (`Magnitude`)

- Highly asymmetric distribution with a dominant baseline peak near faint magnitudes ($+1.1\text{ to }+1.8$ mag) and a long left tail extending to bright magnitudes (down to $-2.95$ mag during opposition flares).
- The mean ($0.70$ mag) is distorted by rare opposition flares and is not very meaningful (giving a magnitude at which Mars is almost never observed). Baseline visual faintness dominates the quantiles (where larger numerical magnitude values denote dimmer visual brightness).

::: {.callout-note collapse="true"}
### Detailed Analysis of Apparent Magnitude
- **Distortion by Rare Events**: For ~90% of its synodic cycle, Mars is far from Earth and faint. During brief opposition alignments, brightness flares up. The mean ($0.70$ mag) is pulled away from the true baseline mode by these rare flares, giving an average value at which Mars is almost never observed.
- **Quantile Collapse**: Because baseline faintness dominates, interquartile range ($IQR$) collapses, hiding the extreme flare range down to $-2.95$ mag during perihelic oppositions.
:::

# 5. Takeaways and Skepticism

1. **Beware the Gaussian Default**: Introductory courses heavily rely on Normal distribution assumptions ($\mu, \sigma^2$). As planetary movements demonstrate, physical processes frequently produce uniform, bimodal, and long-tailed distributions where standard means and variances fail to describe the data.
2. **Summary Tables Condense, But Also Conceal**: Aggregating data points into 8 numbers per variable collapses critical spatial and modal structures (such as bimodal peaks in `Dec` or opposition spikes in `Magnitude`).
3. **Always Look at the Data (EDA First)**: Visual inspection (histograms and KDE density plots) must precede numerical summary calculations. Visual plots immediately reveal multi-modality, skewness, boundary effects, and circular topologies.
4. **Context & Domain Expertise Matter**: Observables are physical measurements over time. Understanding planetary orbits (Kepler's laws, retrogrades, synodic cycles, aphelion slowing) explains *why* distributions take their specific shapes. Note also domain conventions: in astronomy, magnitude is an **inverted logarithmic scale** where larger numbers represent *dimmer* objects, and lower/negative numbers represent *brighter* objects.
5. **Beware of Data Scales, Units, and Transformations**:
   - Variables within the same dataset often use completely different units and scales: `RA` in **hours** ($0–24\text{ h}$), `Dec` in **degrees** ($-90^\circ$ to $+90^\circ$), and `Magnitude` on an **inverted logarithmic scale**.
   - Transforming, standardizing, or normalizing data (e.g. z-score standardization or min-max scaling) requires careful attention to domain units and physical topologies before applying standard algorithms blindly.
6. **Beware of Visualization Artifacts**:
   - Analysts must carefully distinguish between **model assumptions**, **physical mechanisms**, and **smoothing artifacts**.
   - Density estimation algorithms can introduce boundary smoothing effects (such as KDE edge leaks), whereas physical drivers (like Keplerian velocity variations near aphelion) produce genuine non-uniform data structures. Visual inspection must always be paired with physical domain understanding.
