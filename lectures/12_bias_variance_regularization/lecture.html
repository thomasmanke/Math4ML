1. Background & Historical Origins

1.1 Model Complexity in Patient Health Prediction

In medical data science, predicting patient health outcomes—such as Systolic Blood Pressure (\(y\), in \(\text{mmHg}\)) from Body Mass Index (\(x\), in \(\text{kg/m}^2\))—requires balancing model simplicity against expressive power.

  • Underfitting (High Bias): An overly simple linear model ignores true physiological non-linearities, producing systematic prediction errors across all patient subgroups.
  • Overfitting (High Variance): A high-degree polynomial fits random patient measurement noise, leading to erratic predictions on new patients.

1.2 Andrew Ng’s Practical Engineering Perspective

  • Stanford CS229 Principle: Machine learning engineering is an iterative diagnostic science.
  • The Core Question: “When a model underperforms on validation data, which exact fix will improve performance?”
  • Empirical Diagnostics: Rather than guessing, we evaluate training error (\(J_{\text{train}}\)) vs. validation error (\(J_{\text{cv}}\)) and plot Learning Curves.

2. Mathematical Bias-Variance Decomposition

For a true data-generating process \(y = f(x) + \varepsilon\) with zero-mean noise \(\mathbb{E}[\varepsilon] = 0\) and variance \(\text{Var}(\varepsilon) = \sigma^2\), the expected squared prediction error of a model \(\hat{f}(x)\) decomposes into three distinct components:

\[\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \underbrace{\text{Bias}\left[\hat{f}(x)\right]^2}_{\text{Systematic Error}} + \underbrace{\text{Var}\left[\hat{f}(x)\right]}_{\text{Model Instability}} + \underbrace{\sigma^2}_{\text{Irreducible Noise}}\]

where: \[\text{Bias}\left[\hat{f}(x)\right] = \mathbb{E}\left[\hat{f}(x)\right] - f(x)\] \[\text{Var}\left[\hat{f}(x)\right] = \mathbb{E}\left[\left(\hat{f}(x) - \mathbb{E}\left[\hat{f}(x)\right]\right)^2\right]\]

Generate Bias-Variance Comparison Plot 
np.random.seed(42)
x_true = np.linspace(18, 35, 100) # BMI (kg/m^2)
y_true = 110 + 1.2 * x_true + 0.05 * (x_true - 25)**2 # True non-linear Systolic BP

# Noisy patient sample
n_samples = 25
x_train = np.random.uniform(18, 35, n_samples)
y_train = 110 + 1.2 * x_train + 0.05 * (x_train - 25)**2 + np.random.normal(0, 4.0, n_samples)

fig, axes = plt.subplots(1, 3, figsize=(11, 4.0))

degrees = [1, 3, 10]
titles = ['High Bias (Degree 1)\nUnderfitting', 'Balanced (Degree 3)\nOptimal Generalization', 'High Variance (Degree 10)\nOverfitting']
colors = ['crimson', 'darkcyan', 'darkorange']

for idx, (deg, title, col) in enumerate(zip(degrees, titles, colors)):
    model = make_pipeline(PolynomialFeatures(deg), LinearRegression())
    model.fit(x_train.reshape(-1, 1), y_train)
    y_pred = model.predict(x_true.reshape(-1, 1))
    
    axes[idx].scatter(x_train, y_train, color='black', alpha=0.6, label='Patient Samples')
    axes[idx].plot(x_true, y_true, 'g--', lw=1.5, label='True Function $f(x)$')
    axes[idx].plot(x_true, y_pred, color=col, lw=2.5, label=f'Model $\\hat{{f}}(x)$ (deg={deg})')
    axes[idx].set_title(title, fontsize=9, fontweight='bold')
    axes[idx].set_xlabel('BMI ($\text{kg/m}^2$)', fontsize=8)
    axes[idx].set_ylabel('Systolic BP ($\text{mmHg}$)', fontsize=8)
    axes[idx].set_ylim(120, 175)
    axes[idx].legend(fontsize=7, loc='upper left')

plt.tight_layout()
plt.show()

3. Regularization Geometry (L1 Lasso vs. L2 Ridge)

To prevent high variance in complex models, we add a shrinkage penalty \(\Omega(\boldsymbol{w})\) to the objective function:

\[J(\boldsymbol{w}) = \text{MSE}(\boldsymbol{w}) + \lambda \Omega(\boldsymbol{w})\]

  • L2 Ridge Regularization: \(\Omega(\boldsymbol{w}) = \|\boldsymbol{w}\|_2^2 = \sum_{j=1}^D w_j^2\). Shrinks weights smoothly toward zero without setting them exactly to zero.
  • L1 Lasso Regularization: \(\Omega(\boldsymbol{w}) = \|\boldsymbol{w}\|_1 = \sum_{j=1}^D |w_j|\). Enforces sparsity by driving non-essential feature weights to exactly zero.
Generate L1 vs L2 Weight Paths Plot 
np.random.seed(42)
n_features = 8
n_pts = 40
X_mat = np.random.randn(n_pts, n_features)
w_true_vec = np.array([3.0, -2.5, 0.0, 0.0, 1.2, 0.0, -0.8, 0.0])
y_vec = X_mat @ w_true_vec + np.random.normal(0, 0.5, n_pts)

alphas = np.logspace(-3, 2, 100)
ridge_coefs = []
lasso_coefs = []

for a in alphas:
    r_mod = Ridge(alpha=a).fit(X_mat, y_vec)
    l_mod = Lasso(alpha=a, max_iter=5000).fit(X_mat, y_vec)
    ridge_coefs.append(r_mod.coef_)
    lasso_coefs.append(l_mod.coef_)

fig, axes = plt.subplots(1, 2, figsize=(11, 4.0))

axes[0].plot(alphas, ridge_coefs)
axes[0].set_xscale('log')
axes[0].set_title('L2 Ridge Regularization Weight Paths\n(Smooth Weight Decay)', fontsize=10, fontweight='bold')
axes[0].set_xlabel('Penalty Parameter $\\lambda$ (log scale)', fontsize=9)
axes[0].set_ylabel('Weight Value $w_j$', fontsize=9)

axes[1].plot(alphas, lasso_coefs)
axes[1].set_xscale('log')
axes[1].set_title('L1 Lasso Regularization Weight Paths\n(Sparse Feature Selection)', fontsize=10, fontweight='bold')
axes[1].set_xlabel('Penalty Parameter $\\lambda$ (log scale)', fontsize=9)
axes[1].set_ylabel('Weight Value $w_j$', fontsize=9)

plt.tight_layout()
plt.show()

4. Andrew Ng’s Empirical ML System Diagnostics

Following Andrew Ng’s Stanford CS229 Lecture 11 blueprint, we diagnose model performance by comparing Training Error (\(J_{\text{train}}\)) against Validation Error (\(J_{\text{cv}}\)).

4.1 Bias vs. Variance Diagnostic Indicators

  • High Bias (Underfitting):
    • \(J_{\text{train}}\) is high (the model cannot fit the training set).
    • \(J_{\text{cv}} \approx J_{\text{train}}\) (validation error is equally high).
    • Key Insight: Collecting more training data will not help high bias!
  • High Variance (Overfitting):
    • \(J_{\text{train}}\) is very low (the model fits training noise).
    • \(J_{\text{cv}} \gg J_{\text{train}}\) (large generalization gap).
    • Key Insight: Collecting more training data will help high variance!

4.2 Andrew Ng’s “6 Fixes” Decision Matrix

Action / Fix Solves High Bias (Underfitting)? Solves High Variance (Overfitting)?
Get more training data (\(m\)) ❌ Useless ✅ Fixes High Variance
Try a smaller set of features ❌ Useless ✅ Fixes High Variance
Try adding new features / polynomial terms ✅ Fixes High Bias ❌ Useless
Decrease regularization parameter \(\lambda\) ✅ Fixes High Bias ❌ Useless
Increase regularization parameter \(\lambda\) ❌ Useless ✅ Fixes High Variance

4.3 Learning Curves (\(J_{\text{train}}\) vs. \(J_{\text{cv}}\) vs. Sample Size \(m\))

Generate Learning Curves Diagnostic Plot 
m_sizes = np.linspace(10, 200, 20, dtype=int)

# High Bias curves (both high, small gap)
train_err_bias = 15.0 - 10.0 / np.sqrt(m_sizes)
cv_err_bias = 16.0 + 8.0 / np.sqrt(m_sizes)

# High Variance curves (large gap, narrowing with m)
train_err_var = 2.0 + 1.0 * np.log(m_sizes)
cv_err_var = 25.0 - 12.0 * np.log10(m_sizes)

fig, axes = plt.subplots(1, 2, figsize=(11, 4.0))

axes[0].plot(m_sizes, train_err_bias, 'b-o', ms=4, label='Training Loss $J_{\\text{train}}$')
axes[0].plot(m_sizes, cv_err_bias, 'r-o', ms=4, label='Validation Loss $J_{\\text{cv}}$')
axes[0].set_title('High Bias Learning Curve\n(Plateaus early; More data will NOT help)', fontsize=9, fontweight='bold')
axes[0].set_xlabel('Training Sample Size $m$', fontsize=8)
axes[0].set_ylabel('Loss $J(\\boldsymbol{w})$', fontsize=8)
axes[0].set_ylim(0, 30)
axes[0].legend(fontsize=8)

axes[1].plot(m_sizes, train_err_var, 'b-o', ms=4, label='Training Loss $J_{\\text{train}}$')
axes[1].plot(m_sizes, cv_err_var, 'r-o', ms=4, label='Validation Loss $J_{\\text{cv}}$')
axes[1].set_title('High Variance Learning Curve\n(Large gap; More data WILL help)', fontsize=9, fontweight='bold')
axes[1].set_xlabel('Training Sample Size $m$', fontsize=8)
axes[1].set_ylabel('Loss $J(\\boldsymbol{w})$', fontsize=8)
axes[1].set_ylim(0, 30)
axes[1].legend(fontsize=8)

5. Summary & Key Takeaways

NoteSystematic ML Engineering Workflow
  1. Build a Simple Baseline First: Deploy a minimal end-to-end model within 24 hours to establish benchmark metrics (\(J_{\text{train}}\) and \(J_{\text{cv}}\)).
  2. Diagnose Before Fixing: Plot learning curves and compare \(J_{\text{train}}\) vs. \(J_{\text{cv}}\) before choosing a fix.
  3. Use the 6 Fixes Matrix:
    • If High Bias \(\to\) Increase model capacity (add features, decrease \(\lambda\)).
    • If High Variance \(\to\) Constrain model capacity (increase \(\lambda\), prune features, collect more training data).

## 3. Regularization Geometry (L1 Lasso vs. L2 Ridge)

## 4. Andrew Ng's Empirical ML System Diagnostics

- **High Bias (Underfitting)**:
