1. Goal

In the previous lecture, we derived the closed-form analytical OLS solution:

\[\hat{\theta}_{\text{OLS}} = (X^T X)^{-1} X^T y\]

Even if \((X^T X)^{-1}\) exists and is mathematically solvable, there are still important engineering decisions to consider:

  1. Which numerical functions (np.linalg.solve vs. inv) to use to compute \(\hat{\theta}\) in NumPy?

  2. How measurement noise propagates into parameter uncertainty.

  3. How to solve linear models when \(X^T X\) is too large to invert or when exact inversion is computationally intractable.

  4. What to do for non-linear models if the original relationship between \(X\) and \(y\) is not even linear.

2. Solving Normal Equations

NumPy Implementation

In NumPy, we set up the Design Matrix \(X \in \mathbb{R}^{n \times 2}\) (including the bias column of ones) and compute \(\hat{\theta}\):

Code 
import numpy as np

# Synthetic medical dataset (n = 100 patients)
np.random.seed(42)
n = 100
x = np.random.uniform(10, 80, n)  # Carbohydrate Intake (g)
y = 20 + 1.8 * x + np.random.normal(0, 12, n)  # Blood Glucose Response (mg/dL)

# Design matrix X with intercept column
X = np.column_stack([np.ones(n), x])

# Solve Normal Equations using np.linalg.solve (more stable than inv)
theta_ols = np.linalg.solve(X.T @ X, X.T @ y)

print(f"Estimated Intercept (theta_0): {theta_ols[0]:.2f} mg/dL")
print(f"Estimated Slope     (theta_1): {theta_ols[1]:.2f} mg/dL / g")
Estimated Intercept (theta_0): 23.37 mg/dL
Estimated Slope     (theta_1): 1.72 mg/dL / g

Visualization

ax.plot(x_grid, y_grid, color='#1f77b4', linewidth=2.5, label='OLS Fitted Line')

  • Model as Data Compression: Instead of storing 100 individual patient data pairs \((x_i, y_i)\), the linear model compresses the underlying biological signal into just two scalar parameters: \((\theta_0, \theta_1)\).

  • Model as Predictor: The model equation \(\hat{y} = \theta_0 + \theta_1 x\) allows us to predict the expected blood glucose response for new patient carbohydrate intake values \(x\).

  • Interpreting Model Parameters:

    • Baseline (\(\theta_0 \approx 23.37\text{ mg/dL}\)): Expected baseline blood glucose level when carbohydrate intake is zero (\(x = 0\text{ g}\)).
    • Rate of Increase (\(\theta_1 \approx 1.72\text{ mg/dL / g}\)): Expected increase in blood glucose for every additional gram of carbohydrates consumed.

3. Parameter Uncertainty

Intuitive Motivation: Why do parameter estimates contain errors?

When we generated our synthetic patient data, we used true underlying parameters \(\theta_0 = 20.0\text{ mg/dL}\) and \(\theta_1 = 1.80\text{ mg/dL/g}\). However, our OLS calculation estimated \(\hat{\theta}_0 = 23.37\) and \(\hat{\theta}_1 = 1.72\). Why didn’t OLS recover the exact values \(20.0\) and \(1.80\)?

Imagine drawing data from a different sample of 100 patients, or missing a few data points. Because individual biological responses contain random noise, a new sample would yield slightly different estimates (e.g. \(\hat{\theta}_0 = 21.2, \hat{\theta}_1 = 1.79\)). Because our estimates \(\hat{\theta}\) depend on noisy sample observations, the estimated parameters themselves are random variables that carry sampling uncertainty!

Variance of Parameter Estimates

Noise in data measurements propagates through matrix operations into parameter estimate uncertainty according to:

\[\text{Var}(\hat{\theta}) = \sigma^2 (X^T X)^{-1}\]

NoteMathematical Derivation of Var(θ)

In probability theory, the variance of a random parameter vector \(\hat{\theta}\) relative to its mean \(\mathbb{E}[\hat{\theta}] = \theta\) is defined as the expectation of its squared deviation:

\[\text{Var}(\hat{\theta}) = \mathbb{E}\left[ (\hat{\theta} - \mathbb{E}[\hat{\theta}])(\hat{\theta} - \mathbb{E}[\hat{\theta}])^T \right]\]

Because the target \(y = X\theta + \epsilon\) is a sum of a deterministic signal \(X\theta\) (zero variance) and a random noise vector \(\epsilon \sim \mathcal{N}(0, \sigma^2 I)\), the variance in \(y\) comes entirely from the noise term: \(\text{Var}(y) = \text{Var}(\epsilon) = \sigma^2 I\).

Starting from the OLS estimator \(\hat{\theta} = (X^T X)^{-1} X^T y\):

\[\begin{aligned} \text{Var}(\hat{\theta}) &= \text{Var}\left( (X^T X)^{-1} X^T y \right) \\[6pt] &= (X^T X)^{-1} X^T \text{Var}(y) \left( (X^T X)^{-1} X^T \right)^T \\[6pt] &= (X^T X)^{-1} X^T (\sigma^2 I) X (X^T X)^{-1} \\[6pt] &= \sigma^2 (X^T X)^{-1} X^T X (X^T X)^{-1} \\[6pt] &= \sigma^2 (X^T X)^{-1} \end{aligned}\]

ImportantNotice that Var(θ) is a Matrix!

Because we are estimating two parameters (\(\theta_0\) and \(\theta_1\)), the parameter variance \(\text{Var}(\hat{\theta})\) is a \(2 \times 2\) Covariance Matrix:

\[\text{Var}(\hat{\theta}) = \begin{bmatrix} \text{Var}(\hat{\theta}_0) & \text{Cov}(\hat{\theta}_0, \hat{\theta}_1) \\ \text{Cov}(\hat{\theta}_0, \hat{\theta}_1) & \text{Var}(\hat{\theta}_1) \end{bmatrix}\]

  • Diagonal Elements: Represent the individual variance of each parameter. Taking the square root gives the Standard Errors: \(SE(\hat{\theta}_0) = \sqrt{\text{Var}(\hat{\theta}_0)}\) and \(SE(\hat{\theta}_1) = \sqrt{\text{Var}(\hat{\theta}_1)}\).
  • Off-Diagonal Elements: Represent the covariance / correlation between the intercept and slope estimates.
Code 
# Estimate residual variance s^2
residuals = y - X @ theta_ols
sigma_sq = np.sum(residuals**2) / (n - 2)
cov_theta = sigma_sq * np.linalg.inv(X.T @ X)

fig, ax = plt.subplots(figsize=(5.5, 4.5), dpi=300)

        ax.text(j, i, f'{val:.4f}', ha='center', va='center',
                color=text_color, fontsize=12, fontweight='bold')

ax.set_xticks([0, 1])
ax.set_yticks([0, 1])
ax.set_xticklabels([r'$\theta_0$ (Intercept)', r'$\theta_1$ (Slope)'], fontsize=11, fontweight='bold')
ax.set_yticklabels([r'$\theta_0$ (Intercept)', r'$\theta_1$ (Slope)'], fontsize=11, fontweight='bold')

Computing Standard Errors

The Standard Error of parameter estimate \(\hat{\theta}_j\) is defined as the square root of its diagonal variance entry:

\[SE(\hat{\theta}_j) = \sqrt{\text{Var}(\hat{\theta})_{jj}}\]

Code 
# Standard errors are square roots of diagonal elements
se_theta = np.sqrt(np.diag(cov_theta))

print(f"SE(theta_0): {se_theta[0]:.3f} mg/dL")
print(f"SE(theta_1): {se_theta[1]:.3f} mg/dL / g")
SE(theta_0): 2.504 mg/dL
SE(theta_1): 0.053 mg/dL / g

4. Prediction Uncertainty

Error Propagation

Errors in parameter estimates \(\hat{\theta}\) directly translate into uncertainty in model predictions \(\hat{y}(x)\).

For any specific feature vector \(x = [1, x]^T\) (including the lead element \(1\) for the intercept), the predicted output is \(\hat{y}(x) = x^T \hat{\theta}\). Applying matrix variance rules, the variance of the prediction is:

\[\text{Var}(\hat{y}(x)) = \text{Var}\left( x^T \hat{\theta} \right) = x^T \text{Var}(\hat{\theta}) x\]

The standard error of prediction is the square root of this scalar variance:

\[SE(\hat{y}(x)) = \sqrt{x^T \text{Var}(\hat{\theta}) x}\]

Probabilistic Meaning & Multiples

  • Single Standard Error (\(\hat{y} \pm 1 \cdot SE\)): Covers approximately \(68.3\%\) of the sampling probability distribution under a Gaussian error model.
  • Higher Coverage Multiples (\(\hat{y} \pm 1.96 \cdot SE\)): To cover a larger percentage of prediction uncertainty (e.g. \(95\%\) probability coverage), we multiply the standard error by \(1.96\):

\[\text{95\% Confidence Interval} = \hat{y}(x) \pm 1.96 \cdot SE(\hat{y}(x))\]

Code 
# Compute 95% Confidence Band across x_grid
X_grid = np.column_stack([np.ones(len(x_grid)), x_grid])
y_pred = X_grid @ theta_ols

# Vectorized prediction standard error: SE(y_hat(x)) = sqrt(diag(X_grid @ cov_theta @ X_grid.T))
pred_se = np.sqrt(np.sum((X_grid @ cov_theta) * X_grid, axis=1))

fig, ax = plt.subplots(figsize=(8, 4.8), dpi=300)
ax.scatter(x, y, color='#d62728', alpha=0.45, edgecolors='k', linewidth=0.5, label='Data')
ax.plot(x_grid, y_pred, color='#1f77b4', linewidth=2.5, label=r'OLS Fitted Line $\hat{y} = X\hat{\theta}$')
ax.fill_between(x_grid, y_pred - 1.96*pred_se, y_pred + 1.96*pred_se, color='#1f77b4', alpha=0.2, label=r'95% Confidence Band ($\pm 1.96 \cdot SE$)')

ax.set_xlabel('Carbohydrate intake [g]', fontsize=11)
ax.set_ylabel('Blood glucose response [mg/dL]', fontsize=11)
ax.set_title('Parameter Uncertainty & 95% Confidence Band', fontsize=12, pad=12)
ax.grid(True, linestyle='--', alpha=0.5)
ax.legend(loc='lower right', frameon=True)
plt.show()
NoteAnalytical Insert: Uncertainty & Error Propagation

How do errors and uncertainties in the data propagate analytically through parameter estimation into model predictions?

  • Data Uncertainty (Measurement Noise): Assuming observation noise is uncorrelated and homoscedastic with variance \(\sigma^2\): \[\text{Cov}(y) = \sigma^2 I_n \in \mathbb{R}^{n \times n}\]

  • Parameter Uncertainty Propagation: Since \(\hat{\theta} = (X^T X)^{-1} X^T y\) is a linear function of \(y\), covariance propagation \(\text{Cov}(A y) = A \text{Cov}(y) A^T\) yields: \[\text{Cov}(\hat{\theta}) = (X^T X)^{-1} X^T (\sigma^2 I_n) X (X^T X)^{-1} = \sigma^2 (X^T X)^{-1} \in \mathbb{R}^{p \times p}\]

  • In-Sample Prediction Uncertainty Propagation: Propagating parameter uncertainty back to in-sample predictions \(\hat{y} = H y\) via the hat matrix \(H = X(X^T X)^{-1} X^T\): \[\text{Cov}(\hat{y}) = H \text{Cov}(y) H^T = \sigma^2 H H^T = \sigma^2 H \in \mathbb{R}^{n \times n}\] For an individual patient \(i\), the in-sample prediction variance is \(\text{Var}(\hat{y}_i) = \sigma^2 h_{ii}\), where \(h_{ii} = H_{ii}\) is the patient’s leverage.

5. Iterative Optimization

Why Iterative Algorithms?

  1. Computational Complexity: Exact matrix inversion \((X^T X)^{-1}\) requires \(\mathcal{O}(p^3)\) operations. When \(p = 10^6\) features or streaming data \(n \to \infty\), exact inversion is computationally infeasible.

  2. Non-Linear Extensions: In complex Machine Learning and Neural Networks, analytical closed-form solutions do not exist at all, requiring iterative algorithms to approach the optimal parameters.

Gradient Descent Update Rule

We define the Mean Squared Error (MSE) loss \(S(\theta)\) as \(\frac{1}{n} \times \text{RSS}(\theta)\), taking the average squared error across all \(n\) data points:

\[S(\theta) = \frac{1}{n} \text{RSS}(\theta) = \frac{1}{n} \|y - X\theta\|^2 = \frac{1}{n} \sum_{i=1}^n (y_i - x_i^T \theta)^2\]

(Note: Dividing by \(n\) normalizes the Residual Sum of Squares so the loss magnitude remains independent of dataset size \(n\)).

Taking the partial derivative of \(S(\theta)\) with respect to \(\theta\):

\[\frac{\partial S}{\partial \theta} = -\frac{2}{n} X^T \left( y - X\theta \right)\]

Starting from an initial parameter guess \(\theta^{(0)}\), we step iteratively in the direction opposite to the partial derivative:

\[\theta^{(k+1)} = \theta^{(k)} - \alpha \frac{\partial S}{\partial \theta^{(k)}} = \theta^{(k)} + \frac{2\alpha}{n} X^T \left( y - X\theta^{(k)} \right)\]

Code 
# Gradient Descent loop tracking parameters and loss history
theta = np.array([75.0, -0.4])  # Epoch 0: Initial random guess
alpha = 0.0003                  # Single scalar learning rate

loss_history = []
snapshots = {0: theta.copy()}

for epoch in range(1, 4001):
    err = y - X @ theta
    mse = np.mean(err**2)
    loss_history.append(mse)
    grad = -2/n * X.T @ err
    theta -= alpha * grad
    if epoch in [100, 4000]:
        snapshots[epoch] = theta.copy()

print(f"Gradient Descent Intercept (Epoch 4000): {theta[0]:.2f} mg/dL")
print(f"Gradient Descent Slope     (Epoch 4000): {theta[1]:.2f} mg/dL / g")
Gradient Descent Intercept (Epoch 4000): 56.19 mg/dL
Gradient Descent Slope     (Epoch 4000): 1.10 mg/dL / g
Code 
fig, ax = plt.subplots(figsize=(8, 4.8), dpi=300)
ax.scatter(x, y, color='#d62728', alpha=0.45, edgecolors='k', linewidth=0.5, label='Data')

x_grid = np.linspace(10, 80, 200)

# Convenient 3-color scheme for Epochs 0, 100, 4000 (all solid lines)
colors = ['#e377c2', '#ff7f0e', '#1f77b4']

for (ep, th), col in zip(snapshots.items(), colors):
    y_line = th[0] + th[1] * x_grid
    ax.plot(x_grid, y_line, color=col, linewidth=2.5, linestyle='-', label=f'Epoch {ep}')

ax.set_xlabel('Carbohydrate intake [g]', fontsize=11)
ax.set_ylabel('Blood glucose response [mg/dL]', fontsize=11)

6. Review

  • Model Compression: Linear models compress \(n\) data points into a few scalar parameters (for example, \(\theta_0\) and \(\theta_1\)).

  • Model Predictions: Given the parameters, we can predict expected values for any new sample—even for nonsensical input data beyond the original scope (for example, evaluating carbohydrate intake \(x = -100\text{ g}\)).

  • Analytical vs. Iterative Solvers: OLS provides exact closed-form solutions for small \(p\), while Gradient Descent progressively rotates and shifts the line toward the optimal fit.

  • Error Propagation: Noise in data \(\longrightarrow\) uncertain parameter estimates \(\longrightarrow\) uncertain model predictions.

## 3. Parameter Uncertainty

### Intuitive Motivation: Why do parameter estimates contain errors?
When we generated our synthetic patient data, we used true underlying parameters $\theta_0 = 20.0\text{ mg/dL}$ and $\theta_1 = 1.80\text{ mg/dL/g}$. However, our OLS calculation estimated $\hat{\theta}_0 = 23.37$ and $\hat{\theta}_1 = 1.72$. Why didn't OLS recover the exact values $20.0$ and $1.80$?

Imagine drawing data from a *different* sample of 100 patients, or missing a few data points. Because individual biological responses contain random noise, a new sample would yield slightly different estimates (e.g. $\hat{\theta}_0 = 21.2, \hat{\theta}_1 = 1.79$). Because our estimates $\hat{\theta}$ depend on noisy sample observations, **the estimated parameters themselves are random variables** that carry sampling uncertainty!

### Variance of Parameter Estimates
Noise in data measurements propagates through matrix operations into parameter estimate uncertainty according to:

$$\text{Var}(\hat{\theta}) = \sigma^2 (X^T X)^{-1}$$

::: {.callout-note collapse="true"}
### Mathematical Derivation of Var(θ)
In probability theory, the variance of a random parameter vector $\hat{\theta}$ relative to its mean $\mathbb{E}[\hat{\theta}] = \theta$ is defined as the expectation of its squared deviation:

$$\text{Var}(\hat{\theta}) = \mathbb{E}\left[ (\hat{\theta} - \mathbb{E}[\hat{\theta}])(\hat{\theta} - \mathbb{E}[\hat{\theta}])^T \right]$$

Because the target $y = X\theta + \epsilon$ is a sum of a deterministic signal $X\theta$ (zero variance) and a random noise vector $\epsilon \sim \mathcal{N}(0, \sigma^2 I)$, the variance in $y$ comes entirely from the noise term: $\text{Var}(y) = \text{Var}(\epsilon) = \sigma^2 I$.

Starting from the OLS estimator $\hat{\theta} = (X^T X)^{-1} X^T y$:

$$\begin{aligned}
\text{Var}(\hat{\theta}) &= \text{Var}\left( (X^T X)^{-1} X^T y \right) \\[6pt]
&= (X^T X)^{-1} X^T \text{Var}(y) \left( (X^T X)^{-1} X^T \right)^T \\[6pt]
&= (X^T X)^{-1} X^T (\sigma^2 I) X (X^T X)^{-1} \\[6pt]
&= \sigma^2 (X^T X)^{-1} X^T X (X^T X)^{-1} \\[6pt]
&= \sigma^2 (X^T X)^{-1}
\end{aligned}$$
:::

---

::: {.callout-important}
### Notice that Var(θ) is a Matrix!
Because we are estimating two parameters ($\theta_0$ and $\theta_1$), the parameter variance $\text{Var}(\hat{\theta})$ is a **$2 \times 2$ Covariance Matrix**:

$$\text{Var}(\hat{\theta}) = \begin{bmatrix} \text{Var}(\hat{\theta}_0) & \text{Cov}(\hat{\theta}_0, \hat{\theta}_1) \\ \text{Cov}(\hat{\theta}_0, \hat{\theta}_1) & \text{Var}(\hat{\theta}_1) \end{bmatrix}$$

* **Diagonal Elements:** Represent the individual variance of each parameter. Taking the square root gives the **Standard Errors**: $SE(\hat{\theta}_0) = \sqrt{\text{Var}(\hat{\theta}_0)}$ and $SE(\hat{\theta}_1) = \sqrt{\text{Var}(\hat{\theta}_1)}$.
* **Off-Diagonal Elements:** Represent the **covariance / correlation** between the intercept and slope estimates.
:::

### Computing Standard Errors

The **Standard Error** of parameter estimate $\hat{\theta}_j$ is defined as the square root of its diagonal variance entry:

$$SE(\hat{\theta}_j) = \sqrt{\text{Var}(\hat{\theta})_{jj}}$$

```{python}

#| code-fold: show
#| echo: true

print(f"SE(theta_0): {se_theta[0]:.3f} mg/dL")
print(f"SE(theta_1): {se_theta[1]:.3f} mg/dL / g")
```

## 4. Prediction Uncertainty

### Error Propagation

Errors in parameter estimates $\hat{\theta}$ directly translate into uncertainty in model predictions $\hat{y}(x)$.

For any specific feature vector $x = [1, x]^T$ (including the lead element $1$ for the intercept), the predicted output is $\hat{y}(x) = x^T \hat{\theta}$. Applying matrix variance rules, the variance of the prediction is:

$$\text{Var}(\hat{y}(x)) = \text{Var}\left( x^T \hat{\theta} \right) = x^T \text{Var}(\hat{\theta}) x$$

The standard error of prediction is the square root of this scalar variance:

$$SE(\hat{y}(x)) = \sqrt{x^T \text{Var}(\hat{\theta}) x}$$

#### Probabilistic Meaning & Multiples
* **Single Standard Error ($\hat{y} \pm 1 \cdot SE$):** Covers approximately **$68.3\%$** of the sampling probability distribution under a Gaussian error model.
* **Higher Coverage Multiples ($\hat{y} \pm 1.96 \cdot SE$):** To cover a larger percentage of prediction uncertainty (e.g. **$95\%$ probability coverage**), we multiply the standard error by $1.96$:

$$\text{95\% Confidence Interval} = \hat{y}(x) \pm 1.96 \cdot SE(\hat{y}(x))$$

```{python}
#| label: parameter_uncertainty_plot
#| code-fold: true
#| echo: true

# Compute 95% Confidence Band across x_grid
X_grid = np.column_stack([np.ones(len(x_grid)), x_grid])
y_pred = X_grid @ theta_ols

# Vectorized prediction standard error: SE(y_hat(x)) = sqrt(diag(X_grid @ cov_theta @ X_grid.T))
pred_se = np.sqrt(np.sum((X_grid @ cov_theta) * X_grid, axis=1))

fig, ax = plt.subplots(figsize=(8, 4.8), dpi=300)
ax.scatter(x, y, color='#d62728', alpha=0.45, edgecolors='k', linewidth=0.5, label='Data')
ax.plot(x_grid, y_pred, color='#1f77b4', linewidth=2.5, label=r'OLS Fitted Line $\hat{y} = X\hat{\theta}$')
ax.fill_between(x_grid, y_pred - 1.96*pred_se, y_pred + 1.96*pred_se, color='#1f77b4', alpha=0.2, label=r'95% Confidence Band ($\pm 1.96 \cdot SE$)')

ax.set_xlabel('Carbohydrate intake [g]', fontsize=11)
ax.set_ylabel('Blood glucose response [mg/dL]', fontsize=11)
ax.set_title('Parameter Uncertainty & 95% Confidence Band', fontsize=12, pad=12)
ax.grid(True, linestyle='--', alpha=0.5)
ax.legend(loc='lower right', frameon=True)
plt.show()
```

### Analytical Insert: Uncertainty & Error Propagation

How do errors and uncertainties in the data propagate analytically through parameter estimation into model predictions?

* **Data Uncertainty (Measurement Noise):**
  Assuming observation noise is uncorrelated and homoscedastic with variance $\sigma^2$:
  $$\text{Cov}(y) = \sigma^2 I_n \in \mathbb{R}^{n \times n}$$

* **Parameter Uncertainty Propagation:**
  Since $\hat{\theta} = (X^T X)^{-1} X^T y$ is a linear function of $y$, covariance propagation $\text{Cov}(A y) = A \text{Cov}(y) A^T$ yields:
  $$\text{Cov}(\hat{\theta}) = (X^T X)^{-1} X^T (\sigma^2 I_n) X (X^T X)^{-1} = \sigma^2 (X^T X)^{-1} \in \mathbb{R}^{p \times p}$$

* **In-Sample Prediction Uncertainty Propagation:**
  Propagating parameter uncertainty back to in-sample predictions $\hat{y} = H y$ via the hat matrix $H = X(X^T X)^{-1} X^T$:
  $$\text{Cov}(\hat{y}) = H \text{Cov}(y) H^T = \sigma^2 H H^T = \sigma^2 H \in \mathbb{R}^{n \times n}$$
  For an individual patient $i$, the in-sample prediction variance is $\text{Var}(\hat{y}_i) = \sigma^2 h_{ii}$, where $h_{ii} = H_{ii}$ is the patient's **leverage**.

## 5. Iterative Optimization

### Why Iterative Algorithms?
1. **Computational Complexity:** Exact matrix inversion $(X^T X)^{-1}$ requires $\mathcal{O}(p^3)$ operations. When $p = 10^6$ features or streaming data $n \to \infty$, exact inversion is computationally infeasible.

2. **Non-Linear Extensions:** In complex Machine Learning and Neural Networks, analytical closed-form solutions do not exist at all, requiring iterative algorithms to approach the optimal parameters.

---

### Gradient Descent Update Rule

We define the **Mean Squared Error (MSE) loss** $S(\theta)$ as $\frac{1}{n} \times \text{RSS}(\theta)$, taking the average squared error across all $n$ data points:

$$S(\theta) = \frac{1}{n} \text{RSS}(\theta) = \frac{1}{n} \|y - X\theta\|^2 = \frac{1}{n} \sum_{i=1}^n (y_i - x_i^T \theta)^2$$

*(Note: Dividing by $n$ normalizes the Residual Sum of Squares so the loss magnitude remains independent of dataset size $n$).*

Taking the partial derivative of $S(\theta)$ with respect to $\theta$:

$$\frac{\partial S}{\partial \theta} = -\frac{2}{n} X^T \left( y - X\theta \right)$$

Starting from an initial parameter guess $\theta^{(0)}$, we step iteratively in the direction opposite to the partial derivative:

$$\theta^{(k+1)} = \theta^{(k)} - \alpha \frac{\partial S}{\partial \theta^{(k)}} = \theta^{(k)} + \frac{2\alpha}{n} X^T \left( y - X\theta^{(k)} \right)$$

```{python}
#| label: gd_iterative_loop
#| code-fold: show
#| echo: true

# Gradient Descent loop tracking parameters and loss history
theta = np.array([75.0, -0.4])  # Epoch 0: Initial random guess
alpha = 0.0003                  # Single scalar learning rate

loss_history = []
snapshots = {0: theta.copy()}

for epoch in range(1, 4001):
    err = y - X @ theta
    mse = np.mean(err**2)
    loss_history.append(mse)
    grad = -2/n * X.T @ err
    theta -= alpha * grad
    if epoch in [100, 4000]:
        snapshots[epoch] = theta.copy()

print(f"Gradient Descent Intercept (Epoch 4000): {theta[0]:.2f} mg/dL")
print(f"Gradient Descent Slope     (Epoch 4000): {theta[1]:.2f} mg/dL / g")
```

## 6. Review

* **Model Compression:**
  Linear models compress $n$ data points into a few scalar parameters (for example, $\theta_0$ and $\theta_1$).

* **Model Predictions:**
  Given the parameters, we can predict expected values for any new sample—even for nonsensical input data beyond the original scope (for example, evaluating carbohydrate intake $x = -100\text{ g}$).

* **Analytical vs. Iterative Solvers:**
  OLS provides exact closed-form solutions for small $p$, while Gradient Descent progressively rotates and shifts the line toward the optimal fit.

* **Error Propagation:**
  Noise in data $\longrightarrow$ uncertain parameter estimates $\longrightarrow$ uncertain model predictions.
