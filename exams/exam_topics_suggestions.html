Exam & Tutorial Topic Framework Suggestions

This document compiles real-world domain frameworks for designing future written exam questions and flipped lab tutorial tasks in Mathe3. Each domain pairs a feature variable (\(x\)) with a target response (\(y\)) while aligning with core linear algebra and machine learning concepts.

1. Domain Frameworks

1.1 Education & Student Performance

  • Feature Variable (\(x\)): Preparation Duration / Study Hours (\(x\), in hours).
  • Target Variable (\(y\)): Achieved Exam Score (\(y\), in points or %).
  • Model Equation: \(y = \theta_0 + \theta_1 x\)
  • Interpretation: \(\theta_0\) represents baseline knowledge (zero preparation), while \(\theta_1\) represents performance gain per study hour.
  • Exam Application: Standard, highly relatable baseline for \(2 \times 2\) matrix inversion, determinant checks, and parameter estimation.

1.2 Linguistics & Text Mining

  • Feature Variable (\(x\)): Text Document Length / Word Count (\(x\), in thousands of words).
  • Target Variable (\(y\)): Stylometric Vocabulary Richness / Unique Terms (\(y\), in count).
  • Model Equation: \(y = \theta_0 + \theta_1 x\)
  • Interpretation: \(\theta_0\) represents core vocabulary size, while \(\theta_1\) represents lexical expansion rate per 1,000 words.
  • Exam Application: Text mining and natural language processing context. Can be extended to term-document matrices or TF-IDF vector spaces.

1.3 Digital Humanities & Epigraphy

  • Feature Variable (\(x\)): Inscription Weathering / Surface Age (\(x\), in centuries).
  • Target Variable (\(y\)): Optical Character Recognition (OCR) Accuracy (\(y\), in %).
  • Model Equation: \(y = \theta_0 + \theta_1 x\)
  • Interpretation: \(\theta_0\) represents unweathered inscription legibility, while \(\theta_1 < 0\) represents decay loss per century.
  • Exam Application: Digital heritage preservation context. Ideal for overdetermined systems showing noisy decay measurements.

1.4 Political Science & Demographics

  • Feature Variable (\(x\)): Door-to-Door Canvassing / Campaign Effort (\(x\), in hours per district).
  • Target Variable (\(y\)): Voter Turnout Rate (\(y\), in %).
  • Model Equation: \(y = \theta_0 + \theta_1 x\)
  • Interpretation: \(\theta_0\) represents baseline turnout without active campaigning, while \(\theta_1\) represents voter mobilization gain per campaign hour.
  • Exam Application: Social science and public policy context. Excellent for testing linear independence and multi-variable regression.

1.5 Cultural Economics & Art Markets

  • Feature Variable (\(x\)): Exhibition Duration (\(x\), in days).
  • Target Variable (\(y\)): Total Ticket Revenue (\(y\), in thousands of €).
  • Model Equation: \(y = \theta_0 + \theta_1 x\)
  • Interpretation: \(\theta_0\) represents opening-day advance sales, while \(\theta_1\) represents daily visitor revenue rate.
  • Exam Application: Applied economics context for fitting straight lines and calculating parameter vectors via \(\boldsymbol{\theta} = \mathbf{X}^{-1}\mathbf{y}\).

1.6 Audio & Signal Processing

  • Feature Variable (\(x\)): Audio Sampling Frequency (\(x\), in kHz).
  • Target Variable (\(y\)): Reconstructed Signal Fidelity / SNR (\(y\), in dB).
  • Model Equation: \(y = \theta_0 + \theta_1 x\)
  • Interpretation: \(\theta_0\) represents base signal noise floor, while \(\theta_1\) represents fidelity improvement per kHz.
  • Exam Application: Signal processing and engineering context. Good for demonstrating degenerate systems when two sample rates yield identical measurements.

2. Mathematical Alignment Checklist for Exam Questions

When selecting a domain framework for an exam question, verify that it supports the intended 10–15 minute hand-calculation task:

Mathematical Concept Exam Task Requirements Ideal Domain Framework
\(2 \times 2\) Matrix Inversion Given 2 distinct data points, construct \(\mathbf{X}\), calculate \(\det(\mathbf{X}) = ad-bc \neq 0\), compute \(\mathbf{X}^{-1}\), and solve \(\boldsymbol{\theta} = \mathbf{X}^{-1}\mathbf{y}\). Education, Cultural Economics, Linguistics.
Degenerate System & Rank Given 2 duplicated data points, construct \(\mathbf{X}\), show \(\det(\mathbf{X}) = 0\), verify \(\text{rank}(\mathbf{X}) = 1 < 2\), and state why \(\mathbf{X}^{-1}\) does not exist. Audio Processing, Epigraphy.
Overdetermined System (\(3 \times 2\)) Given 3 non-collinear points, set up \([\mathbf{X} \mid \mathbf{y}]\), perform Gaussian elimination to reach REF \([0 \quad 0 \mid c]\), and prove contradiction (\(0 = c\)). Political Science, Digital Humanities.
