Task 1: Data Preparation

  • Target Encoding & Missing Values: Inspect the raw target Diagnosis and encode it such that \(y = 1\) (Malignant) and \(y = 0\) (Benign). Check for and remove any missing values if present.
  • Feature Matrix & Class Imbalance: Define the feature matrix \(\mathbf{X}\) and target vector \(y\). Investigate the class distribution and determine the malignant disease prevalence \(\bar{p}\).
  • Stratified Split & Standardization: Create a stratified train/test split (80% train, 20% test) and standardize the features using StandardScaler.

Task 2: Baseline Model

  • Prevalence, Odds & Null Deviance: Using the training data, define a baseline model with no predictors and only use the prevalence \(\bar{p}\) for all observations. Calculate the odds, log-odds, and the null deviance of the training data \[D_0 = -2 \sum_{i=1}^n [y_i \ln \bar{p} + (1 - y_i)\ln(1 - \bar{p})]\]

  • Intercept-Only Logistic Regression: Fit a logistic regression model with only an intercept term, extract the fitted parameter \(\hat{\theta}_0\), and compare to the baseline log-odds.

  • Baseline Plot: Plot the observed target values and the null model prediction \(\hat{p} = \bar{p}\) for all samples (you may sort by sample index).

Task 3: Univariate Logistic Regression

  • Univariate Models & Ranking: Conduct univariate logistic regressions for each feature \(j\) independently. Compute the residual deviance \(D(x_j)\) and the deviance drop relative to the null model, \(\Delta D_j = D_0 - D(x_j)\). Display the ranking table.
  • Sigmoid & Linear Log-Odds: For the top-ranked feature, plot both the predicted probability \(\hat{p}(x)\) and the log-odds \(z(x)\).
  • Parameter Interpretation & Threshold: Interpret the slope parameter \(\theta_1\) and determine the decision threshold \(x^*\) where \(\hat{p} = 0.5\).

Task 4: Bivariate Logistic Regression

  • Bivariate Model: Fit a bivariate logistic regression using the top biomarker from Task 3 \(x_1\) (worst perimeter) and a second biomarker \(x_2\) (worst texture).
  • 2D Probability Gradient & Decision Boundary: Plot the predicted probability \(\hat{p}\) across the 2D grid \((x_1, x_2)\) as a smooth contour gradient and plot the observed data points colored distinctly by disease status (Benign vs. Malignant).
  • Deviance Progression: Calculate the residual deviance \(D_2\) and confirm that \(D_2 < D_1 < D_0\).

Task 5: Loss Landscape

  • Scan Parameter: Fix the intercept \(\theta_0 = \hat{\theta}_{0}\) from Model 1 and scan the slope parameter \(\theta_1\) across a broad range around the best prediction, \(\theta_1 \in [-5 |\hat{\theta}_1|, +5 |\hat{\theta}_1|]\).
  • Loss Curves Comparison: Compute and plot the Binary Cross-Entropy (BCE) and Mean Squared Error (MSE) for predictions \(\hat{y}_i = \sigma(x_i^T \theta)\). What are the key differences in the asymptotic behavior of BCE vs. MSE?

Task 6: Multivariate Logistic Regression

  • Full Model Fitting: Fit a multivariable logistic regression using all standardized features.
  • Deviance Comparison: Compare the residual deviance \(D\), and deviance drop \(\Delta D\) for the four models (Model 0: Null, Model 1: Univariate, Model 2: Bivariate, Model 3: Full).

Task 7: Model Evaluation

  • Evaluation on the Test Set: Evaluate the fitted full model (Model 3) on the unseen test set (\(\mathbf{X}_{\text{test}}\), \(\mathbf{y}_{\text{test}}\)) using a decision threshold of \(t = 0.5\). Calculate and visualize the Confusion Matrix using scikit-learn, and calculate Sensitivity (Recall), Specificity, Precision, and Accuracy.
  • Diagnostic Curves: Plot the ROC and Precision-Recall curves for the test set predictions, including the AUC and Average Precision (AP) scores.

Task 8: Optional Regularization

The default implementation of LogisticRegression() in scikit-learn applies \(L_2\) Ridge regularization with a default penalty strength of \(C=1.0\). Explore the impact of this parameter on model performance. An alternative regularization approach is \(L_1\) Lasso, which can drive redundant collinear features to exact zero, yielding a sparser model. You can explore this with parameters C, l1_ratio=1 and solver='saga'. How many features remain active (non-zero) under Lasso? Which are removed?

Checkpoint and Review Questions

  • Question 2 (Parameter Interpretation & Odds Ratios): In logistic regression, how is a fitted slope parameter \(\theta_j\) interpreted in terms of the Odds Ratio (\(\text{OR}_j = \exp(\theta_j)\))? What does it mean for the odds if \(\theta_j > 0\), \(\theta_j = 0\), or \(\theta_j < 0\)?
  • Question 3 (Confusion Matrix & ROC): In medical diagnostics, why is overall classification accuracy often misleading? Name two complementary metrics from the confusion matrix that distinguish between error types. Explain what the ROC curve shows. Why is AUC a useful summary statistic?
